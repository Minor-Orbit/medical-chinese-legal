# 개인정보처리방침

시행 예정일: 앱 최초 출시일  
최종 개정: 2026년 10월 2일

`의료 중국어 - 병원 회화·통역 연습`(이하 “앱”)은 회원가입과 자체 서버 없이 작동하는 한국어·중국어 학습 앱입니다.

## 앱이 저장하는 정보

- 즐겨찾기, 사용자 추가 단어와 메모, 숨긴 콘텐츠, 재생 속도, 화면 언어와 테마는 기기 내부에 저장됩니다.
- 학습한 단어·회화의 식별자, 진료 영역별 이용 횟수, 단어·통역 연습 및 녹음 횟수, 앱 공유 여부, 누적 학습일과 획득 뱃지 판정에 필요한 진행 기록을 기기 내부에 저장합니다.
- 이어서 학습을 위해 마지막으로 재생한 회화와 문장 위치를 기기 내부에 저장합니다. 회화를 끝까지 재생하거나 다음 회화로 이동하면 해당 이어보기 기록은 제거됩니다.
- 보상형 광고로 해금한 추가 회화의 식별자와 2시간 배너 광고 숨김 만료 시각을 기기 내부에 저장합니다.
- 사용자가 녹음을 시작한 경우에만 마이크를 사용합니다.
- 녹음은 문장과 연습 방향별 최신 파일 한 개만 앱 전용 내부 저장공간에 보관됩니다.
- 개발자는 위 학습 기록과 녹음에 접근하거나 자체 서버로 전송하지 않습니다.

녹음은 재녹음, 개별 삭제, 학습 기록 초기화 또는 앱 삭제 시 제거됩니다. 녹음 파일은 Android 클라우드 백업과 기기 이전 대상에서 제외됩니다.

## 음성 읽기

번들 MP3가 없는 항목은 기기에 설정된 Android TTS 엔진을 사용합니다. 앱은 TTS 문장을 개발자 서버로 전송하지 않지만, 선택된 TTS 엔진의 처리와 개인정보 정책은 해당 엔진 제공자의 정책을 따릅니다.

## 광고

앱에는 Google AdMob 광고가 포함됩니다. Google과 광고 파트너는 IP 주소, 광고 식별자, 앱 상호작용 및 진단정보 등을 광고 제공·측정·분석·부정 사용 방지 목적으로 처리할 수 있습니다. 앱은 Google User Messaging Platform을 이용해 관련 지역에서 필요한 동의 또는 개인정보 선택 화면을 제공합니다.

사용자가 명시적으로 선택한 경우 보상형 광고가 표시될 수 있습니다. 광고 시청 보상으로 일부 추가 회화를 기기에서 해금하거나 2시간 동안 배너 광고와 해당 영역을 숨길 수 있습니다. 해금 여부와 만료 시각은 계정이나 개발자 서버가 아닌 기기 내부에만 저장됩니다. 광고를 보지 않아도 앱의 기본 학습 콘텐츠는 이용할 수 있습니다.

## 보유와 삭제

앱의 학습 기록, 성취·뱃지 진행도, 이어보기 위치, 광고 보상 상태, 설정과 녹음은 앱 전용 저장공간에 보관되며 Android 클라우드 백업과 기기 이전 대상에서 제외됩니다. 사용자가 앱 안에서 관련 기록을 초기화하거나 앱을 제거하면 함께 제거됩니다. 초기화할 때에는 획득한 뱃지와 광고로 해금한 추가 회화도 초기화될 수 있음을 앱에서 안내합니다. 계정과 개발자 서버가 없으므로 별도의 서버 계정 삭제 요청 절차는 없습니다.

## 어린이와 의료정보

앱은 아동을 대상으로 설계되지 않았으며, 증상이나 진료기록을 개발자에게 전송하지 않습니다. 민감한 개인정보가 포함된 내용을 녹음하지 않는 것을 권장합니다.
