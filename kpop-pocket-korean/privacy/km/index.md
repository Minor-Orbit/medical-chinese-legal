# ព័ត៌មានឯកជនភាព

2026-10-28 · K-pop Pocket Korean (`com.minororbit.fankorean`)

នេះជាសេចក្តីសង្ខេបជាភាសាខ្មែរ។ សូមអានគោលការណ៍ពេញលេញជាភាសាអង់គ្លេសសម្រាប់ព័ត៌មានលម្អិត។

មិនត្រូវការគណនីទេ។ ប្រវត្តិរៀន ឃ្លារក្សាទុក សំណុំហាត់ ការកំណត់ និងសំឡេងថតនៅលើឧបករណ៍។ យើងមិនមានម៉ាស៊ីនមេសិក្សា ឬសេវាវិភាគការរៀនផ្ទាល់ខ្លួនទេ។

ការថតសំឡេងជាជម្រើស និងត្រូវការការអនុញ្ញាតមីក្រូហ្វូន។ ថតបានរហូតដល់ ៣០ វិនាទី។ ការថតថ្មីដែលបានរក្សាទុកជោគជ័យជំនួសការថតចាស់សម្រាប់ឃ្លានោះ។ កម្មវិធីមិនផ្ញើសំឡេងថតទៅអ្នកអភិវឌ្ឍ សេវាពាណិជ្ជកម្ម ឬសេវា AI ទេ។

សំឡេងមេរៀន និងតួអង្គបានបង្កើតទុក និងមាននៅក្នុងកម្មវិធី។ ការស្តាប់មិនស្នើសុំ Google Cloud TTS, fal.ai ឬ ElevenLabs ឱ្យបង្កើតសំឡេងថ្មីទេ។ លំហាត់ហង់ហ្គូលខ្លះប្រើសំឡេង Android ដែលដំឡើងក្នុងឧបករណ៍ ហើយអ្នកផ្តល់សេវានោះអាចមានការដំណើរការទិន្នន័យតាមគោលការណ៍ផ្ទាល់ខ្លួន។

កម្មវិធីប្រើ Google AdMob, Google UMP និង Unity Ads។ សេវាទាំងនេះអាចដំណើរការអាសយដ្ឋាន IP លេខសម្គាល់ឧបករណ៍ឬពាណិជ្ជកម្ម សកម្មភាពក្នុងកម្មវិធីនិងពាណិជ្ជកម្ម និងព័ត៌មានវិនិច្ឆ័យ សម្រាប់ពាណិជ្ជកម្ម ការវាស់វែង និងការទប់ស្កាត់ការក្លែងបន្លំ។ ដូច្នេះ មិនអាចនិយាយថាកម្មវិធីទាំងមូលមិនមានការដំណើរការទិន្នន័យទេ។ ជម្រើសការយល់ព្រមនិងឯកជនភាពអាចខុសគ្នាតាមតំបន់ និងការកំណត់សេវា។

ការចែករំលែកសំណុំហាត់ផ្ញើឈ្មោះសំណុំ លេខសម្គាល់ឃ្លា លំដាប់ និងកំណែទៅកម្មវិធីដែលអ្នកជ្រើសរើស។ មិនរួមបញ្ចូលសំឡេងថត ឬរង្វាន់ពាណិជ្ជកម្មទេ។ ការបម្រុងទុកដោយខ្លួនឯងមានទិន្នន័យរៀននិងសំណុំមួយចំនួន។ ប្រសិនបើអ្នកជ្រើសសេវាឯកសារលើអ៊ីនធឺណិត សេវានោះអាចផ្ទុកឯកសារឡើង។

អាចលុបធាតុនិងសំឡេងថតដែលកម្មវិធីអនុញ្ញាតបាន។ ដើម្បីលុបទិន្នន័យក្នុងឧបករណ៍ទាំងអស់ សូមលុបទិន្នន័យកម្មវិធីក្នុងការកំណត់ Android ឬលុបកម្មវិធី។ ឯកសារដែលបាននាំចេញត្រូវលុបដោយឡែក។ យើងមិនអាចលុបទិន្នន័យដែលនៅតែក្នុងឧបករណ៍ពីចម្ងាយបានទេ។
