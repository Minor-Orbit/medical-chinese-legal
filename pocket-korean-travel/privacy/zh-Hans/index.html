韩国旅游：景点与实用韩语 · Minor Orbit
曾用名: HANTEUM: Travel Korean / Pocket Korean: Korea Travel
com.minororbit.koreatravel
生效日期: 2026-11-07
隐私联系邮箱: davidleepub@gmail.com

1. 关于本应用

Minor Orbit 的 韩国旅游：景点与实用韩语（com.minororbit.koreatravel）面向成年游客。无需账号，也没有开发者运营的学习服务器。课程和景点地图数据随应用提供。我们未另外接入开发者自己的分析或崩溃报告服务。广告 SDK、语音引擎和外部服务可能各自处理数据。

2. 保存在设备上的信息

应用私有存储保存收藏的表达、课程及韩文字母进度、测验结果、偏好、使用日期、评价提醒与 K-pop 推荐选项、广告同意、横幅暂停时间、本地广告统计和已验证的广告配置。学习记录不会上传给我们。应用无法得知您是否已发表商店评价。本地广告日志只记录结果类别和数字代码，不含录音或课程正文，应用不会上传这些日志。

3. 可选的麦克风录音

仅在您选择录音练习时请求麦克风权限，拒绝不会影响其他课程。每段最长30秒。点击保存会保留草稿，并替换该表达之前的录音，可在应用内删除。录音不会上传给开发者、广告或 AI 服务。应用不进行语音识别或自动发音评分。

4. MP3 与 Android 朗读

内置 MP3 在本地播放，不调用语音生成 API。选择 Android 文字转语音或某句缺少录音时，应用只向已安装的引擎提供固定课程文字，不提供麦克风录音。网络使用、语音下载和诊断信息取决于引擎及提供商。应用使用过程中不会通过 Google Cloud TTS、fal.ai 或 ElevenLabs API 生成语音。

5. 广告与提供商处理的数据

应用使用 Unity Ads 直接 SDK 4.21.0、Google AdMob SDK 25.5.0 和 Google UMP。默认启用 Unity、停用 AdMob；经验证的远程配置可更改启用的广告网络。两者均启用并准备就绪时，首次请求按 Unity 80%、AdMob 20%选择，失败时最多切换一次。这不保证实际展示比例。应用向 Unity 传递仅限情境广告的隐私标志，但不代表完全不处理数据。提供商为广告、衡量、功能和反欺诈收集或共享 IP 推算的大致位置、设备或账号等标识符、应用及广告互动和诊断信息。Unity 也列明购买历史；本应用没有应用内购买，不向两家公司发送学习记录或录音。其他应用活动的收集取决于 Unity 的 Acquire Optimization 设置。官方披露链接见下方。

6. 广告隐私选择

Google UMP 检查是否可请求广告，并在需要时显示同意表单；设置中也会在需要时显示广告隐私选项。您还可使用 Android 广告 ID 设置和 Unity 广告内的隐私选项，包括向提供商请求删除数据。自愿观看奖励视频且确认完成后，横幅暂停2小时。拒绝或跳过不会锁定课程。暂停横幅并不保证所有 SDK 处理停止。

7. 签名配置与 GitHub

应用在前台使用期间，最多每6小时检查一次 GitHub Pages 上的固定 HTTPS 配置文件。GitHub 会接收 IP 地址和请求信息，不会收到学习历史或录音。应用验证签名、应用标识、版本及允许值。配置只控制广告网络启用状态和首次选择权重，不能传入代码、任意网址、广告 ID 或绕过同意。离线或验证失败时，最后一次有效配置会继续保存在本地，不设到期时间。本隐私页面也托管于 GitHub Pages。

8. 地图、学习网站与其他链接

内置地图不请求 GPS，也不提供实时导航。打开 Google Maps 时可能传递景点名称或坐标，而非设备位置。旅游信息、图片来源、语音提供商、HANTEUM Hangul/Korean 及商店链接会打开外部服务，后者可能按各自政策处理连接数据。HANTEUM 链接只包含支持的语言和课程路径，不附带身份信息或学习记录。网站进度与应用进度分别保存。

9. 分享、评价与导出文件

分享应用仅把显示的介绍文字和商店链接交给您选择的分享应用，不附带录音或学习历史。发表评价或打开推荐的 K-pop 应用使用 Google Play 或浏览器。通过 Android 文档选择器导出的地图许可 ZIP 只含地图数据与署名信息，不含个人学习数据；您选择的云端文档提供商可能上传该文件。

10. 保存期限与删除

可在应用内移除收藏和录音。通过 Android 设置 → 应用 → 韩国旅游：景点与实用韩语 → 存储 → 清除存储，或卸载应用，可移除本地进度、偏好、录音、提醒选项及横幅暂停记录。应用备份规则禁用了 Android 自动备份及应用数据迁移。导出文件和语音引擎下载需另行管理。我们无法远程获取或删除仅存于设备的数据。提供商自行管理其处理数据的保留和删除。

11. 安全、跨境处理与权利

远程配置使用 HTTPS；Google 和 Unity 声明其 SDK 数据在传输中加密。应用使用 Android 私有存储，不声称提供额外的端到端加密。提供商可能按各自政策在您所在国家以外处理数据。您的权利取决于适用法律，可联系我们提出访问、更正、删除或异议请求；其他提供商的数据请联系相应提供商。界面语言或发行国家限制不会免除您的隐私权利。

12. 支持、儿童与本网站

发送支持邮件会向我们提供邮箱地址及您发送的内容，用于回复和解决请求，并按支持需要及适用义务保留。可请求删除，但须遵守相关义务。请勿发送密码或不必要的私人录音。应用并非为儿童设计，也不收集年龄档案。本政策网站没有额外分析、广告或表单；入口页在本地根据浏览器语言选择译文，也可手动切换。政策变化时更新生效日期。联系：davidleepub@gmail.com。
