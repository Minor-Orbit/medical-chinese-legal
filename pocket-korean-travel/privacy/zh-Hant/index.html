隱私權政策

HANTEUM: 旅行韓語 · Minor Orbit
舊名稱: Pocket Korean: Korea Travel
com.minororbit.koreatravel
生效日期: 2026-11-02
隱私聯絡信箱: davidleepub@gmail.com

1. 關於本應用程式

Minor Orbit 的 HANTEUM: 旅行韓語（com.minororbit.koreatravel）適用於成年旅客。不需帳號，也沒有開發者營運的學習伺服器。教材和景點地圖資料隨應用程式提供。我們未另行加入開發者自己的分析或當機回報服務。廣告 SDK、語音引擎與外部服務可能各自處理資料。

2. 儲存在裝置上的資訊

應用程式專用儲存空間會保存收藏的表達、課程與韓文字母進度、測驗結果、偏好設定、使用日期、評價提醒與 K-pop 推薦選項、廣告同意、橫幅暫停時間、本機廣告統計及已驗證的廣告設定。學習紀錄不會上傳給我們。應用程式無法得知您是否已發表商店評價。本機廣告紀錄只含結果類別與數字代碼，不含錄音或教材本文，也不會上傳。

3. 選擇性的麥克風錄音

只有在您選擇錄音練習時才要求麥克風權限，拒絕不會影響其他課程。每段最長30秒。儲存後會保留草稿並取代該表達先前的錄音，可於應用程式內刪除。錄音不會上傳給開發者、廣告或 AI 服務。應用程式不進行語音辨識或自動發音評分。

4. MP3 與 Android 朗讀

內建 MP3 在本機播放，不呼叫語音生成 API。選擇 Android 文字轉語音或某句缺少錄音時，應用程式只將固定教材文字交給已安裝的引擎，不提供麥克風錄音。網路使用、語音下載與診斷資訊取決於引擎及供應商。使用期間不會透過 Google Cloud TTS、fal.ai 或 ElevenLabs API 生成語音。

5. 廣告與供應商的資料處理

應用程式使用 Unity Ads 直接 SDK 4.21.0、Google AdMob SDK 25.5.0 與 Google UMP。預設啟用 Unity、停用 AdMob；經驗證的遠端設定可更改啟用的廣告聯播網。兩者皆啟用並準備完成時，首次請求依 Unity 80%、AdMob 20%選擇，失敗時最多切換一次。這不保證實際曝光比例。應用程式向 Unity 傳遞僅限情境廣告的隱私旗標，但不代表不處理任何資料。供應商為廣告、成效衡量、功能及防詐騙收集或分享由 IP 推算的大略位置、裝置或帳號等識別碼、應用程式及廣告互動和診斷資訊。Unity 也列出購買紀錄；本應用程式沒有應用程式內購買，不向兩家公司傳送學習紀錄或錄音。其他應用程式活動的收集取決於 Unity 的 Acquire Optimization 設定。官方揭露連結見下方。

6. 廣告隱私選擇

Google UMP 會檢查是否可請求廣告，並在需要時顯示同意表單；設定中也會在需要時顯示廣告隱私選項。您也可使用 Android 廣告 ID 設定及 Unity 廣告內的隱私功能，包括向供應商請求刪除資料。自願觀看獎勵影片且確認完成後，橫幅暫停2小時。拒絕或略過不會鎖定課程。暫停橫幅並不保證所有 SDK 處理都停止。

7. 簽章設定與 GitHub

應用程式在前景使用時，最多每6小時檢查一次 GitHub Pages 的固定 HTTPS 設定檔。GitHub 會收到 IP 位址與請求資訊，不會收到學習歷程或錄音。應用程式驗證簽章、應用程式識別、版本與允許值。設定只控制廣告聯播網啟用狀態及首次選擇權重，不能傳入程式碼、任意網址、廣告 ID 或繞過同意。離線或驗證失敗時，最後的有效設定會繼續保存在本機，不設到期日。本政策頁面也託管於 GitHub Pages。

8. 地圖、學習網站與外部連結

內建地圖不要求 GPS，也不提供即時導航。開啟 Google Maps 可能傳送景點名稱或座標，而非您的裝置位置。觀光資訊、照片來源、語音供應商、HANTEUM Hangul/Korean 及商店連結會開啟外部服務，後者可能依自己的政策處理連線資料。HANTEUM 連結只含支援語言與課程路徑，不附加身分資訊或學習紀錄。網站進度與應用程式進度分別保存。

9. 分享、評價與匯出檔案

分享應用程式只會將顯示的介紹文字與商店連結交給您選擇的分享應用程式，不附帶錄音或學習歷程。發表評價或開啟推薦的 K-pop 應用程式會使用 Google Play 或瀏覽器。透過 Android 文件選擇器匯出的地圖授權 ZIP 只含地圖資料與署名資訊，不含個人學習資料；您選擇的雲端文件供應商可能上傳該檔案。

10. 保存期限與刪除

可於應用程式內移除收藏與錄音。透過 Android 設定 → 應用程式 → HANTEUM: 旅行韓語 → 儲存空間 → 清除儲存空間，或解除安裝，可移除本機進度、偏好、錄音、提醒選項與橫幅暫停紀錄。應用程式備份規則已停用 Android 自動備份與資料移轉。匯出檔案及語音引擎下載需另行管理。我們無法遠端取得或刪除僅存於裝置的資料。供應商自行管理其資料的保留與刪除。

11. 安全、跨境處理與權利

遠端設定使用 HTTPS；Google 與 Unity 表示其 SDK 資料在傳輸中加密。應用程式使用 Android 專用儲存空間，不宣稱提供額外端對端加密。供應商可能依自己的政策在您所在國家以外處理資料。您的權利依適用法律而定，可聯絡我們提出存取、更正、刪除或異議請求；其他供應商的資料請洽該供應商。介面語言或發行國家限制不會使您的隱私權失效。

12. 支援、兒童與本網站

寄送支援電子郵件會向我們提供您的信箱與寄送內容，用於回覆及解決請求，並依支援需要及適用義務保留。可請求刪除，但須遵守相關義務。請勿寄送密碼或不必要的私人錄音。應用程式並非為兒童設計，也不收集年齡檔案。本政策網站沒有額外分析、廣告或表單；入口頁在本機依瀏覽器語言選擇譯文，也可手動切換。變更時會更新生效日期。聯絡：davidleepub@gmail.com。
