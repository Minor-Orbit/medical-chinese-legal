1. เกี่ยวกับแอป

เที่ยวเกาหลี: คู่มือและภาษา (com.minororbit.koreatravel) โดย Minor Orbit ออกแบบสำหรับนักท่องเที่ยวผู้ใหญ่ ไม่มีบัญชีหรือเซิร์ฟเวอร์การเรียนที่ผู้พัฒนาดูแล บทเรียนและข้อมูลแผนที่รวมอยู่ในแอป เราไม่ได้เพิ่มบริการวิเคราะห์หรือรายงานแอปขัดข้องของผู้พัฒนาแยกต่างหาก SDK โฆษณา ระบบเสียง และบริการภายนอกอาจประมวลผลข้อมูลของตนเอง

2. ข้อมูลที่เก็บในอุปกรณ์

พื้นที่ส่วนตัวของแอปเก็บวลีที่บันทึก ความคืบหน้าบทเรียนและฮันกึล ผลแบบทดสอบ การตั้งค่า วันที่ใช้งาน ตัวเลือกเตือนรีวิวและแนะนำ K-pop ความยินยอมโฆษณา เวลาพักแบนเนอร์ ตัวนับโฆษณาในเครื่อง และการตั้งค่าโฆษณาที่ตรวจสอบแล้ว ไม่ส่งประวัติเรียนให้เรา แอปไม่ทราบว่าคุณเขียนรีวิวแล้วหรือไม่ บันทึกวินิจฉัยโฆษณาในเครื่องมีเฉพาะประเภทผลและรหัสตัวเลข ไม่มีเสียงหรือเนื้อหาบทเรียน และไม่อัปโหลด

3. การอัดเสียงตามสมัครใจ

ขอสิทธิ์ไมโครโฟนเมื่อคุณเลือกอัดเสียงฝึกเท่านั้น ปฏิเสธแล้วยังเรียนได้ อัดได้ครั้งละไม่เกิน 30 วินาที การบันทึกจะเก็บฉบับร่างแทนเสียงเดิมของวลีนั้น และลบได้ในแอป ไม่อัปโหลดเสียงให้ผู้พัฒนา บริการโฆษณา หรือ AI ไม่มีการรู้จำเสียงหรือให้คะแนนการออกเสียงอัตโนมัติ

4. MP3 และเสียง Android

MP3 ที่รวมมาเล่นในเครื่องโดยไม่เรียก API สร้างเสียง คุณเลือกการอ่านออกเสียง Android ได้ หรือแอปอาจใช้เมื่อไม่มีไฟล์เสียง ส่งเพียงข้อความบทเรียนที่กำหนดไว้ให้ระบบเสียงที่ติดตั้ง ไม่ส่งเสียงไมโครโฟน การใช้เครือข่าย ดาวน์โหลดเสียง และข้อมูลวินิจฉัยขึ้นอยู่กับระบบและผู้ให้บริการ แอปไม่สร้างเสียงผ่าน API ของ Google Cloud TTS, fal.ai หรือ ElevenLabs ระหว่างใช้งาน

5. โฆษณาและข้อมูลของผู้ให้บริการ

แอปมี Unity Ads SDK โดยตรง 4.21.0 และ Google AdMob SDK 25.5.0 พร้อม Google UMP ค่าเริ่มต้นเปิด Unity และปิด AdMob แต่การตั้งค่าระยะไกลที่ยืนยันแล้วเปลี่ยนได้ เมื่อทั้งสองเปิดและพร้อม คำขอแรกเลือก Unity 80% หรือ AdMob 20% และสลับเครือข่ายเมื่อผิดพลาดได้ไม่เกินหนึ่งครั้ง ไม่รับประกันสัดส่วนการแสดงจริง แอปส่งแฟล็กความเป็นส่วนตัวให้ Unity ใช้โฆษณาตามบริบทเท่านั้น แต่ไม่ได้หมายความว่าไม่มีการประมวลผลข้อมูล ผู้ให้บริการเก็บหรือแชร์ตำแหน่งโดยประมาณจาก IP ตัวระบุบุคคล/อุปกรณ์/บัญชี การโต้ตอบกับแอปหรือโฆษณา และข้อมูลวินิจฉัย เพื่อโฆษณา วัดผล ให้บริการ และป้องกันทุจริต Unity ยังระบุประวัติซื้อ แต่แอปนี้ไม่มีการซื้อในแอปและไม่ส่งประวัติเรียนหรือเสียงให้ทั้งสองราย การเก็บกิจกรรมแอปอื่นขึ้นอยู่กับ Acquire Optimization ของ Unity ดูเอกสารทางการด้านล่าง

6. ตัวเลือกเกี่ยวกับโฆษณา

Google UMP ตรวจว่าขอโฆษณาได้หรือไม่ และแสดงแบบยินยอมเมื่อจำเป็น ตัวเลือกความเป็นส่วนตัวโฆษณาจะแสดงในการตั้งค่าเมื่อจำเป็น คุณยังใช้การควบคุมรหัสโฆษณา Android และเมนูความเป็นส่วนตัวในโฆษณา Unity รวมถึงขอลบข้อมูลกับผู้ให้บริการได้ วิดีโอรับรางวัลเป็นทางเลือก เมื่อยืนยันว่าดูจบจะพักแบนเนอร์ 2 ชั่วโมง การปฏิเสธหรือข้ามไม่ล็อกบทเรียน การพักแบนเนอร์ไม่รับประกันว่า SDK จะหยุดประมวลผลทั้งหมด

7. การตั้งค่ามีลายเซ็นและ GitHub

ขณะอยู่เบื้องหน้า แอปตรวจไฟล์ HTTPS ที่อยู่คงที่บน GitHub Pages ไม่เกินหนึ่งครั้งทุก 6 ชั่วโมง GitHub ได้ข้อมูลเชื่อมต่อ เช่น IP และข้อมูลคำขอ แต่ไม่ได้ประวัติเรียนหรือเสียง แอปตรวจลายเซ็น ตัวระบุแอป รุ่น และค่าที่อนุญาต การตั้งค่าเปลี่ยนได้เฉพาะเครือข่ายที่เปิดและน้ำหนักคำขอแรก ไม่ใช่โค้ด URL อิสระ รหัสโฆษณา หรือการข้ามความยินยอม หากออฟไลน์หรือตรวจไม่ผ่าน จะเก็บค่าที่ถูกต้องล่าสุดในเครื่องโดยไม่หมดอายุ หน้านโยบายนี้อยู่บน GitHub Pages ด้วย

8. แผนที่และลิงก์ภายนอก

แผนที่ในแอปไม่ขอ GPS และไม่ใช่ระบบนำทางสด การเปิด Google Maps อาจส่งชื่อหรือพิกัดสถานที่ท่องเที่ยว ไม่ใช่ตำแหน่งอุปกรณ์ ลิงก์ท่องเที่ยว แหล่งภาพ ผู้ให้บริการเสียง HANTEUM Hangul/Korean และร้านแอป เปิดบริการภายนอกที่ใช้นโยบายของตนเอง ลิงก์ HANTEUM มีเพียงภาษาที่รองรับและเส้นทางหลักสูตร ไม่แนบตัวตนหรือประวัติเรียน ความคืบหน้าเว็บไซต์แยกจากแอป

9. แชร์ รีวิว และไฟล์

การแชร์แอปส่งเฉพาะข้อความแนะนำที่แสดงและลิงก์ร้านไปยังแอปที่คุณเลือก ไม่แนบเสียงหรือประวัติเรียน การรีวิวและเปิดแอป K-pop ที่แนะนำใช้ Google Play หรือเบราว์เซอร์ ZIP ใบอนุญาตแผนที่ที่ส่งออกผ่านตัวเลือกเอกสาร Android มีข้อมูลแผนที่และเครดิต ไม่มีข้อมูลเรียนส่วนตัว ผู้ให้บริการเอกสารคลาวด์ที่คุณเลือกอาจอัปโหลดไฟล์นั้น

10. การเก็บรักษาและลบ

ลบวลีและเสียงด้วยเมนูในแอป การตั้งค่า Android → แอป → เที่ยวเกาหลี: คู่มือและภาษา → ที่เก็บข้อมูล → ล้างพื้นที่เก็บข้อมูล หรือถอนการติดตั้ง จะลบความคืบหน้า การตั้งค่า เสียง ตัวเลือกเตือน และเวลาพักแบนเนอร์ในเครื่อง กฎของแอปปิดการสำรองอัตโนมัติ Android และการย้ายข้อมูลแอป ไฟล์ส่งออกและเสียงที่ดาวน์โหลดต้องจัดการแยก เราไม่สามารถดึงหรือลบข้อมูลที่อยู่เฉพาะในอุปกรณ์จากระยะไกล ผู้ให้บริการจัดการการเก็บและลบข้อมูลของตนเอง

11. ความปลอดภัย การประมวลผลข้ามประเทศ และสิทธิ

การตั้งค่าระยะไกลใช้ HTTPS; Google และ Unity ระบุว่าเข้ารหัสข้อมูล SDK ระหว่างส่ง แอปใช้ที่เก็บส่วนตัว Android ไม่ได้อ้างว่ามีการเข้ารหัสจากต้นทางถึงปลายทางเพิ่มเติม ผู้ให้บริการอาจประมวลผลนอกประเทศตามนโยบายของตน สิทธิขึ้นอยู่กับกฎหมายที่ใช้บังคับ คุณติดต่อเราเรื่องเข้าถึง แก้ไข ลบ หรือคัดค้าน และติดต่อผู้ให้บริการสำหรับข้อมูลของเขาได้ ภาษาแอปหรือข้อจำกัดประเทศเผยแพร่ไม่ได้ยกเลิกสิทธิความเป็นส่วนตัว

12. การช่วยเหลือ เด็ก และเว็บไซต์นี้

อีเมลช่วยเหลือทำให้เราได้รับที่อยู่อีเมลและเนื้อหาที่ส่ง ใช้เพื่อตอบและแก้ปัญหา เก็บตามความจำเป็นและหน้าที่ที่ใช้บังคับ ขอให้ลบได้ภายใต้หน้าที่เหล่านั้น อย่าส่งรหัสผ่านหรือเสียงส่วนตัวที่ไม่จำเป็น แอปไม่ได้ออกแบบสำหรับเด็กและไม่เก็บโปรไฟล์อายุ เว็บไซต์นี้ไม่เพิ่มการวิเคราะห์ โฆษณา หรือแบบฟอร์ม หน้าแรกเลือกคำแปลจากภาษาเบราว์เซอร์ภายในเครื่อง และคุณเปลี่ยนภาษาได้ เมื่อแก้นโยบายจะเปลี่ยนวันที่มีผล ติดต่อ: davidleepub@gmail.com
