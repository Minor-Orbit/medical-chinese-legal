Tanggal berlaku: 2026-11-02

1. Tentang aplikasi

Pocket Korean: Korea Travel (com.minororbit.koreatravel), oleh Minor Orbit, ditujukan bagi wisatawan dewasa. Tidak ada akun atau server pembelajaran milik pengembang. Pelajaran dan data peta wisata disertakan dalam aplikasi. Kami tidak menambahkan layanan analitik atau pelaporan kerusakan tersendiri. SDK iklan, mesin suara, dan layanan luar dapat memproses data masing-masing.

2. Informasi di perangkat

Penyimpanan privat aplikasi menyimpan ungkapan tersimpan, progres pelajaran dan Hangul, hasil kuis, preferensi, tanggal penggunaan, pilihan pengingat ulasan dan rekomendasi K-pop, persetujuan iklan, waktu jeda banner, penghitung iklan lokal, serta setelan iklan terverifikasi. Catatan belajar tidak diunggah kepada kami. Aplikasi tidak mengetahui apakah Anda sudah menulis ulasan. Log iklan lokal hanya berisi kategori hasil dan kode angka, tanpa rekaman atau teks pelajaran; log tidak diunggah.

3. Rekaman mikrofon opsional

Izin mikrofon hanya diminta ketika Anda memilih merekam latihan. Menolak tidak mengunci pelajaran. Rekaman maksimal 30 detik. Menyimpan mempertahankan draf dan mengganti rekaman lama untuk ungkapan itu. Rekaman dapat dihapus dalam aplikasi. Audio tidak diunggah ke pengembang, layanan iklan, atau AI. Tidak ada pengenalan ucapan atau penilaian pelafalan otomatis.

4. MP3 dan suara Android

MP3 bawaan diputar lokal tanpa memanggil API pembuat suara. Teks-ke-ucapan Android dapat dipilih atau digunakan saat rekaman tidak tersedia. Hanya teks pelajaran tetap yang dikirim ke mesin terpasang, bukan rekaman mikrofon. Penggunaan jaringan, unduhan suara, dan diagnostik bergantung pada mesin dan penyedianya. Aplikasi tidak membuat suara melalui API Google Cloud TTS, fal.ai, atau ElevenLabs saat digunakan.

5. Iklan dan data penyedia

Aplikasi memakai Unity Ads SDK langsung 4.21.0 dan Google AdMob SDK 25.5.0 dengan Google UMP. Setelan awal mengaktifkan Unity dan menonaktifkan AdMob; konfigurasi jarak jauh terverifikasi dapat mengubahnya. Jika keduanya aktif dan siap, permintaan pertama dipilih dengan peluang Unity 80% dan AdMob 20%, dengan maksimal satu perpindahan jika gagal. Ini bukan jaminan rasio tayangan. Unity menerima penanda privasi untuk iklan kontekstual saja; bukan berarti tidak ada pemrosesan data. Penyedia mengumpulkan atau membagikan perkiraan lokasi dari IP, pengenal pribadi/perangkat/akun, interaksi aplikasi/iklan, dan diagnostik untuk iklan, pengukuran, fungsi, serta pencegahan penipuan. Unity juga mencantumkan riwayat pembelian; aplikasi ini tidak memiliki pembelian dalam aplikasi dan tidak mengirim catatan belajar atau rekaman kepada kedua penyedia. Aktivitas aplikasi lainnya bergantung pada setelan Acquire Optimization Unity. Tautan pengungkapan resmi ada di bawah.

6. Pilihan iklan

Google UMP memeriksa apakah iklan boleh diminta dan menampilkan formulir persetujuan bila diperlukan. Opsi privasi iklan tampil di Setelan jika diwajibkan. Anda juga dapat menggunakan kontrol ID iklan Android dan kontrol privasi pada iklan Unity, termasuk meminta penghapusan data kepada penyedia. Video berhadiah opsional menjeda banner selama 2 jam setelah penyelesaian dikonfirmasi. Menolak atau melewati video tidak mengunci pelajaran. Jeda banner tidak menjamin semua pemrosesan SDK berhenti.

7. Setelan bertanda tangan dan GitHub

Saat berada di latar depan, aplikasi memeriksa berkas HTTPS tetap di GitHub Pages paling sering sekali setiap 6 jam. GitHub menerima data koneksi seperti IP dan metadata permintaan, bukan riwayat belajar atau rekaman. Tanda tangan, identitas aplikasi, versi, dan nilai yang diizinkan diperiksa. Setelan hanya mengubah jaringan aktif dan bobot permintaan awal, bukan kode, URL bebas, ID iklan, atau pengabaian persetujuan. Jika offline atau verifikasi gagal, setelan valid terakhir tetap disimpan lokal tanpa kedaluwarsa. Kebijakan ini juga dihosting di GitHub Pages.

8. Peta dan tautan luar

Peta bawaan tidak meminta GPS atau menyediakan navigasi langsung. Membuka Google Maps dapat mengirim nama atau koordinat objek wisata, bukan lokasi perangkat Anda. Tautan pariwisata, sumber foto, penyedia suara, HANTEUM Hangul/Korean, dan toko membuka layanan luar dengan kebijakan masing-masing. Tautan HANTEUM berisi bahasa yang didukung dan jalur kursus, tanpa identitas atau catatan belajar. Progres situs terpisah dari aplikasi.

9. Berbagi, ulasan, dan berkas

Berbagi aplikasi hanya meneruskan teks promosi yang ditampilkan dan tautan toko ke aplikasi pilihan Anda, tanpa rekaman atau riwayat belajar. Ulasan dan aplikasi K-pop yang direkomendasikan dibuka melalui Google Play atau browser. ZIP lisensi peta yang diekspor lewat pemilih dokumen Android berisi data peta dan atribusi, bukan data belajar pribadi. Penyedia dokumen cloud pilihan Anda dapat mengunggah berkas tersebut.

10. Penyimpanan dan penghapusan

Hapus ungkapan tersimpan dan rekaman melalui kontrol aplikasi. Setelan Android → Aplikasi → Pocket Korean: Korea Travel → Penyimpanan → Hapus penyimpanan, atau mencopot aplikasi, menghapus progres, preferensi, rekaman, pilihan pengingat, serta catatan jeda banner lokal. Aturan aplikasi menonaktifkan pencadangan otomatis Android dan transfer data aplikasi. Berkas ekspor dan suara unduhan dikelola terpisah. Kami tidak dapat mengambil atau menghapus dari jauh data yang hanya ada di perangkat. Penyedia mengelola retensi dan penghapusan data mereka sendiri.

11. Keamanan, pemrosesan internasional, dan hak

Setelan jarak jauh memakai HTTPS; Google dan Unity menyatakan data SDK dienkripsi saat dikirim. Aplikasi memakai penyimpanan privat Android, tanpa klaim enkripsi ujung ke ujung tambahan. Penyedia dapat memproses data di luar negara Anda sesuai kebijakannya. Hak Anda bergantung pada hukum yang berlaku; hubungi kami untuk akses, koreksi, penghapusan, atau keberatan, dan penyedia terkait untuk datanya. Bahasa antarmuka dan batasan negara distribusi tidak menghapus hak Anda.

12. Dukungan, anak-anak, dan situs ini

Email dukungan memberikan alamat email Anda dan isi pesan kepada kami. Data digunakan untuk menjawab dan menyelesaikan permintaan serta disimpan sesuai kebutuhan dukungan dan kewajiban yang berlaku. Anda dapat meminta penghapusan dengan memperhatikan kewajiban tersebut. Jangan kirim kata sandi atau rekaman pribadi yang tidak perlu. Aplikasi tidak dirancang bagi anak-anak dan tidak mengumpulkan profil usia. Situs ini tidak menambahkan analitik, iklan, atau formulir; halaman awal memakai bahasa browser secara lokal untuk memilih terjemahan, yang dapat Anda ubah. Perubahan ditandai tanggal berlaku baru.
