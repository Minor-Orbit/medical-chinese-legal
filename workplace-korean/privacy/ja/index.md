# プライバシーポリシー

適用日：2026年10月24日。対象は **Workplace Korean: Learn Korean（한국일터／Practical Workplace Korean）** のみです。Android パッケージ：`com.minororbit.workplacekorean`。開発者・お問い合わせ：[davidleepub@gmail.com](mailto:davidleepub@gmail.com)。

## 1. アカウントなしで学習
韓国語の同梱レッスン、任意のハングル入門、クイズ、保存した表現の復習、活動バッジを提供します。アカウントは不要で、開発者は学習データ用サーバーを運営していません。端末内の学習履歴を解析・クラッシュ報告基盤経由で受信することもありません。ただし、広告、Android 音声サービス、バックアップ、外部サイトは別途情報を処理する場合があります。

## 2. 端末に保存する記録
レッスン・保存表現の識別子、学習位置、完了回数・日付、練習の回答・進捗、復習記録、学習・復習日、言語・音声・速度・自動再生・ホーム案内の設定を保存します。広告報酬による解放、広告休止時刻、案内の挨拶・表示順の記録も保存します。旧版の一日の目標設定が残る場合がありますが、現設定画面にその機能はありません。紹介バッジが記録するのは Android 共有画面を開いた事実で、送信や相手への到達ではありません。これらはアプリ専用データベース・設定に保管し、学習、再開、設定、報酬に使用します。開発者の学習サーバーには送信しません。

## 3. 任意のマイク練習
録音を選んだ時にマイク権限を求めます。拒否して他の学習機能を利用できます。録音は聞き直し用にアプリ専用フォルダーへ保存し、同じ練習項目で再録音すると以前の録音を置き換えます。開発者、広告 SDK、AI サービスへ録音をアップロードせず、音声認識・自動発音採点もしません。他人の無断録音は避けてください。専用の録音削除ボタンはなく、その端末でのアプリ保存領域消去・アンインストールにより削除できます。

## 4. 同梱 MP3 と Android TTS
MP3 は同梱された韓国語音声を再生し、学習文を開発者の音声サーバーへ送りません。端末 TTS も選択でき、MP3 がない場合と任意のハングル入門では端末 TTS を使います。学習文をインストール済み Android 読み上げエンジンに渡します。音声や通信の要否はエンジン・選択音声に依存します。オフライン音声もありますが、音声データの取得、ネットワーク音声、診断は提供元のサービス・方針の対象となる場合があります。練習録音を TTS に渡しません。インストール済みアプリ内で開発者の Google Cloud TTS、fal.ai、ElevenLabs API キーを用いた音声生成は行いません。音声名・開発時サンプルはクラウド API のアプリ内利用を意味しません。

## 5. 広告とプライバシーの選択
Unity 対応版には Unity Ads SDK 4.16.6、Google Mobile Ads SDK 25.5.0、Google UMP が含まれます。両社のバナー・任意のリワード広告を使用します。プライバシー条件を満たし両 SDK が準備できた場合、最初の要求を概ね Unity 80％・Google 20％で選択します。読み込み失敗時は準備済みの他社に一度だけ切り替えることがあります。一社のみ準備できた場合はその一社を使います。表示回数の比率を保証するものではなく、旧版は Google のみの場合があります。
広告事業者・提携先は広告、測定、不正対策のため IP アドレス、推定される大まかな位置、端末・広告識別子、操作情報、診断情報を処理する場合があります。GPS 位置、連絡先、写真ライブラリの権限は求めません。UMP で同意情報を取得し、その広告要求可否に基づき SDK 初期化を制御します。Unity の開発者側同意フラグは false で、個別最適化広告への同意を表明しません。UMP が必要と判断した場合は設定に広告プライバシー選択を表示します。選択肢は Google の設定・地域に依存します。Android の広告 ID 設定も利用できます。バナー休止は SDK の全処理停止を保証しません。
任意の広告報酬でバナーを2時間休止できます。別の報酬で追加レッスンパックを解放します。報酬は端末内に保存され、有料購入、現金、譲渡可能なアカウント権利ではありません。利用可否は広告サービスと正常な完了に依存します。
Google は SDK 通信に TLS を使うと説明しています。Google・Unity・提携先の処理・保存は各社の方針に従い、国外で行われる場合があります。下記の公式方針・データ開示をご覧ください。アプリは学習履歴・マイク録音を広告要求に添付しません。
Unity のデータ開示には SDK・ユーザー識別子、購入履歴情報、広告操作も含まれますが、本アプリが氏名、メール、銀行・カード情報を尋ねたりアプリ内購入を提供したりする意味ではありません。開発者のアカウント情報や購入イベントを Unity に送りません。広告・アトリビューション処理と端末内の学習報酬は別です。Unity は任意の Acquire Optimization 有効時のアプリ使用時間情報も説明しています。

## 6. Android バックアップと端末移行
自動バックアップが有効で、データベース、共有設定、設定 DataStore を対象に含みます。端末・アカウント設定に応じ OS が提供元のサービスで学習・設定をバックアップする場合があります。設定上、録音フォルダーはクラウドバックアップから除外し、端末間移行には含めます。実際の挙動は Android、端末、提供元に依存します。独自クラウド同期・手動学習バックアップ書き出しはありません。クラウドコピーは開発者でなく端末・アカウント側で管理してください。端末の消去だけで過去の OS バックアップ削除は保証されず、再インストール・移行時に復元される場合があります。

## 7. 保存・削除・安全性
データは各機能での削除、置換、保存領域消去、アンインストールまで残ります。表現の保存解除は保存カードの関連だけを外し、練習完了履歴は消しません。Android 設定 → アプリ → Workplace Korean → ストレージ → データを消去、またはアンインストールで端末内データを削除できます。解放・設定も削除されますが、OS 復元の影響を受けます。バックアップ・音声データは各提供元の設定で管理してください。開発者は端末だけにあるデータを遠隔で閲覧・削除できません。Android の専用領域を使いますが、追加のエンドツーエンド暗号化や侵害端末での保護を保証しません。広告データの保存・削除は各広告事業者が管理します。

## 8. 外部リンク・共有・サポート・対象者
ハングル教材、方針、音声サービス・ダウンロードは外部サービスを開き、各社が方針に従って要求・端末情報を受け取る場合があります。本書は GitHub Pages でホストし、GitHub が IP 等の要求情報を処理する場合があります。学習履歴サーバーではありません。紹介共有は定型文を Android 共有画面で選んだアプリへ渡し、録音・学習履歴は添付しません。選んだアプリが自身の方針で送信します。サポートメールでは送信者アドレスと任意に提供した内容を受け取り、回答に利用します。パスワードや不要な私的録音を送らないでください。成人の職場学習者向けで、子供向けサービスではありません。アプリ内年齢プロフィールは収集しません。

## 9. お問い合わせ・更新
ご質問、プライバシーに関するご依頼、誤りは上記アドレスへ Workplace Korean の件と明記してご連絡ください。処理方法の変更時は適用日を更新し、重要な変更は適切なアプリ内・リリース情報で案内します。
