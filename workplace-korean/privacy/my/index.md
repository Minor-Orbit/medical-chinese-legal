# ကိုယ်ရေးအချက်အလက် မူဝါဒ

အကျိုးသက်ရောက်ရက်: 2026 အောက်တိုဘာ 24။ **Workplace Korean: Learn Korean (한국일터 / Practical Workplace Korean)** အတွက်သာဖြစ်သည်။ Android ပက်ကေ့ချ်: `com.minororbit.workplacekorean`။ ဖန်တီးသူ/အကူအညီ: [davidleepub@gmail.com](mailto:davidleepub@gmail.com)။

## 1. အကောင့်မလိုဘဲ လေ့လာခြင်း
အက်ပ်တွင် ကိုရီးယားသင်ခန်းစာ၊ ရွေးချယ်နိုင်သော ဟန်ဂုလ်အခြေခံ၊ မေးခွန်း၊ သိမ်းထားသောစကားစု ပြန်လေ့ကျင့်ခြင်းနှင့် တံဆိပ်များပါသည်။ အကောင့်မလိုပါ။ ဖန်တီးသူက သင်ယူဒေတာဆာဗာ မလည်ပတ်သကဲ့သို့ ခွဲခြမ်းစိတ်ဖြာ/အက်ပ်ပျက်ကွက်မှုစနစ်မှ စက်တွင်းသင်ယူမှတ်တမ်း မရယူပါ။ ကြော်ငြာ၊ Android အသံ၊ အရန်သိမ်းခြင်းနှင့် ပြင်ပဝက်ဘ်ဆိုက်တို့က အချက်အလက်သီးခြား ကိုင်တွယ်နိုင်သည်။

## 2. စက်တွင်းမှတ်တမ်း
သင်ခန်းစာ/စကားစု ID၊ ရောက်နေသောနေရာ၊ ပြီးစီးအကြိမ်/ရက်၊ လေ့ကျင့်အဖြေ/တိုးတက်မှု၊ ပြန်လေ့ကျင့်မှတ်တမ်း၊ လေ့လာ/ပြန်လေ့ကျင့်ရက်၊ ဘာသာစကား၊ အသံ၊ အမြန်နှုန်း၊ အလိုအလျောက်ဖွင့်ခြင်းနှင့် အကူအညီဆက်တင် သိမ်းသည်။ ကြော်ငြာဆုဖြင့် ဖွင့်ထားမှု၊ ကြော်ငြာရပ်ချိန်နှင့် အကူနှုတ်ဆက်/အလှည့် မှတ်တမ်းလည်းသိမ်းသည်။ အဟောင်းတွင် နေ့စဉ်ပန်းတိုင် ကျန်နိုင်သော်လည်း လက်ရှိဆက်တင်၌ မပါ။ အက်ပ်မိတ်ဆက်တံဆိပ်သည် Android မျှဝေမျက်နှာပြင် ဖွင့်ခြင်းသာမှတ်သည်၊ ပို့ပြီး/လက်ခံသူထံရောက်ခြင်း မဟုတ်။ အက်ပ်သီးသန့်ဒေတာဘေ့စ်/ဆက်တင်တွင် သင်ယူ၊ ဆက်လေ့လာ၊ ဆက်တင်နှင့်ဆုအတွက် သိမ်းသည်၊ ဖန်တီးသူသင်ယူဆာဗာသို့ မတင်ပါ။

## 3. ရွေးချယ်နိုင်သော မိုက်လေ့ကျင့်မှု
အသံသွင်းရန်ရွေးမှ မိုက်ခွင့်တောင်းသည်။ ငြင်းပြီး အခြားလုပ်ဆောင်ချက်သုံးနိုင်သည်။ ပြန်နားထောင်ရန် သီးသန့်ဖိုင်တွဲ၌ရှိပြီး တူညီသောလေ့ကျင့်မှု ထပ်သွင်းလျှင် အဟောင်းအစားထိုးသည်။ ဖန်တီးသူ၊ ကြော်ငြာ SDK သို့မဟုတ် AI သို့ မတင်ပါ။ စကားသံခွဲခြားခြင်း/အသံထွက်အလိုအလျောက်အမှတ်ပေးခြင်း မရှိ။ သူတစ်ပါးကို ခွင့်မရှိဘဲ မသွင်းပါနှင့်။ သီးသန့်အသံဖျက်ခလုတ်မရှိ; အက်ပ်သိုလှောင်မှုရှင်းခြင်း သို့မဟုတ် အက်ပ်ဖျက်ခြင်းက ထိုတပ်ဆင်မှုအသံများကို ဖျက်သည်။

## 4. MP3 နှင့် Android TTS
MP3 သည် အက်ပ်နှင့်ပါသော ကိုရီးယားအသံဖွင့်ပြီး စာသားကို ဖန်တီးသူအသံဆာဗာသို့ မပို့ပါ။ စက် TTS ရွေးနိုင်သည်။ MP3 မရှိခြင်းနှင့် ရွေးချယ်နိုင်သော ဟန်ဂုလ်လမ်းညွှန်တွင် စက် TTS သုံးသည်။ စာသားကို တပ်ဆင်ထားသော Android TTS အင်ဂျင်သို့ ပေးသည်။ အသံ/ကွန်ရက်လိုအပ်မှု အင်ဂျင်နှင့်အသံပေါ်မူတည်သည်; အချို့အော့ဖ်လိုင်းဖြစ်သော်လည်း အသံဒေတာဒေါင်းလုဒ်၊ အွန်လိုင်းအသံနှင့် ချို့ယွင်းချက်စစ်ဆေးမှုသည် ဝန်ဆောင်မှုပေးသူ၏မူဝါဒနှင့် သက်ဆိုင်နိုင်သည်။ လေ့ကျင့်သွင်းသံကို TTS သို့ မပေးပါ။ တပ်ဆင်အက်ပ်က ဖန်တီးသူ၏ Google Cloud TTS, fal.ai သို့မဟုတ် ElevenLabs API ကီးနှင့် အသံမထုတ်ပါ။ အသံအမည်/ဖွံ့ဖြိုးဆဲနမူနာသည် ထိုကလောက်ဒ် API များ အက်ပ်အတွင်းလည်ပတ်သည်ဟု မဆိုလိုပါ။

## 5. ကြော်ငြာနှင့် ကိုယ်ရေးရွေးချယ်မှု
Unity ဗားရှင်းတွင် Unity Ads SDK 4.16.6, Google Mobile Ads SDK 25.5.0 နှင့် Google UMP ပါသည်။ နှစ်ခုစလုံးက ဘန်နာနှင့် ရွေးချယ်ဆုကြော်ငြာပေးသည်။ ကိုယ်ရေးစည်းကမ်းပြီး SDK နှစ်ခုအသင့်ဖြစ်လျှင် ပထမတောင်းဆိုမှုကို ခန့်မှန်း Unity 80%/Google 20% ရွေးသည်; ဖွင့်မရလျှင် အခြားအသင့်ဝန်ဆောင်မှုကို တစ်ကြိမ်ပြောင်းစမ်းနိုင်သည်။ တစ်ခုသာအသင့်ဖြစ်လျှင် ထိုတစ်ခုသုံးသည်။ တောင်းဆိုမှုခွဲခြင်းသာဖြစ်ပြီး ပြသမှုအချိုးအာမခံ မဟုတ်; အဟောင်း၌ Google သာဖြစ်နိုင်သည်။
SDK/မိတ်ဖက်များသည် ကြော်ငြာ၊ တိုင်းတာမှုနှင့် အလွဲသုံးမှုတားဆီးရန် IP၊ ခန့်မှန်းအကြမ်းဖျဉ်းတည်နေရာ၊ စက်/ကြော်ငြာ ID၊ တုံ့ပြန်မှုနှင့် ချို့ယွင်းချက်ဒေတာ ကိုင်တွယ်နိုင်သည်။ GPS၊ အဆက်အသွယ် သို့မဟုတ် ဓာတ်ပုံသိုလှောင်မှု မတောင်းပါ။ UMP က သဘောတူအချက်အလက်တောင်းပြီး ကြော်ငြာတောင်းနိုင်သည့်ရလဒ်ဖြင့် SDK စတင်ခြင်းထိန်းသည်။ Unity ဖန်တီးသူဘက်ကိုယ်ရေးသဘောတူ flag သည် false ဖြစ်ပြီး စိတ်ကြိုက်ကြော်ငြာသဘောတူထားသည်ဟု မဆိုပါ။ UMP လိုအပ်လျှင် ဆက်တင်တွင် ကြော်ငြာကိုယ်ရေးရွေးချယ်မှု ပြသည်; ပုံစံသည် Google ဆက်တင်/ဒေသပေါ်မူတည်သည်။ Android ကြော်ငြာ ID ထိန်းချုပ်မှုလည်းရှိသည်။ ဘန်နာရပ်ခြင်းက SDK လုပ်ဆောင်မှုအားလုံး ရပ်မည်ဟု မအာမခံ။
ရရှိပြီးသော ရွေးချယ်ဆုသည် ဘန်နာကို 2 နာရီရပ်သည်; သီးခြားဆုက ထပ်ဆောင်းသင်ခန်းစာပက်ကေ့ချ်ဖွင့်သည်။ စက်တွင်းဆုသည် ငွေပေးဝယ်ယူမှု၊ ငွေသား သို့မဟုတ် လွှဲနိုင်သောအကောင့်အခွင့်အရေးမဟုတ်။ ရရှိမှုသည် ကြော်ငြာဝန်ဆောင်မှုနှင့် အောင်မြင်ပြီးစီးမှုအပေါ်မူတည်သည်။
Google က SDK ပို့ဆောင်မှု TLS သုံးကြောင်းဆိုသည်။ Google, Unity နှင့် မိတ်ဖက်တို့သည် ကိုယ်ပိုင်မူဝါဒအရ နိုင်ငံပြင်ပတွင်လည်း ကိုင်တွယ်/သိမ်းနိုင်သည်; အောက်ပါတရားဝင်လင့်ခ်ကြည့်ပါ။ အက်ပ်က စက်တွင်းသင်ယူမှတ်တမ်း/သွင်းသံကို ကြော်ငြာတောင်းဆိုမှုနှင့် မတွဲပါ။ Unity ထုတ်ဖော်ချက်တွင် SDK/သုံးသူ ID၊ ဝယ်ယူမှတ်တမ်းအချက်အလက်နှင့် ကြော်ငြာတုံ့ပြန်မှုလည်း ပါသည်။ အက်ပ်က အမည်၊ အီးမေးလ်၊ ဘဏ်/ကတ်တောင်းခြင်း သို့မဟုတ် အက်ပ်အတွင်းဝယ်ယူမှု ပေးခြင်းဟု မဆိုလိုပါ။ ဖန်တီးသူအကောင့်ပရိုဖိုင်/ဝယ်ယူဖြစ်ရပ် Unity သို့မပို့ပါ။ ကြော်ငြာ/မူလရင်းမြစ်သတ်မှတ်ခြင်းသည် စက်တွင်းလေ့လာဆုနှင့် သီးခြားဖြစ်သည်။ ရွေးချယ် Acquire Optimization ဖွင့်ထားသည့်အခါ အက်ပ်သုံးချိန်ကိုလည်း Unity ဖော်ပြသည်။

**2026-10-28** — ဗားရှင်းအသစ်များတွင် အတည်ပြုထားသော အဝေးမှဆက်တင်ဖြင့် ကြော်ငြာပံ့ပိုးသူများကို ဖွင့်ပိတ်နိုင်သည်။ အစတွင် Unity ကိုသာဖွင့်ပြီး AdMob ကိုပိတ်ထားသည်။ နှစ်ခုလုံးဖွင့်ထားပြီး အသင့်ဖြစ်မှ 80:20 ရွေးချယ်မှုကို အသုံးပြုသည်။ အက်ပ်ကို ရှေ့မျက်နှာပြင်သို့ ပြန်ယူလာသည့်အခါ အများဆုံး 6 နာရီလျှင် တစ်ကြိမ် HTTPS မှတစ်ဆင့် GitHub Pages မှ ဒစ်ဂျစ်တယ်လက်မှတ်ပါ အများပြည်သူသုံးဆက်တင်ဖိုင်ကို ရယူသည်။ ထိုတောင်းဆိုမှုတွင် အက်ပ်က သင်ယူမှုမှတ်တမ်း၊ အသံဖမ်းဖိုင် သို့မဟုတ် ကြော်ငြာအမှတ်အသားများကို မထည့်ပါ။ ဝက်ဘ်ဆိုက်ဝန်ဆောင်မှုပေးသူက IP လိပ်စာအပါအဝင် ချိတ်ဆက်မှုအချက်အလက်ကို ရရှိသည်။ အင်တာနက်မရှိချိန်တွင် နောက်ဆုံးအတည်ပြုထားသောဆက်တင်ကို သက်တမ်းမကုန်ဘဲ သိမ်းထားသည်။ ကြော်ငြာစစ်ဆေးရေးမှတ်တမ်းကို စက်၏ Android log တွင်သာရေးပြီး အက်ပ်က အပ်လုဒ်မတင်ပါ။

## 6. အရန်သိမ်းနှင့် စက်ပြောင်း
