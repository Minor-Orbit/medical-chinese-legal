# 隐私政策

生效日期：2026年10月24日。本政策仅适用于 **Workplace Korean: Learn Korean（한국일터／Practical Workplace Korean）**。Android 包名：`com.minororbit.workplacekorean`。开发者及支持：[davidleepub@gmail.com](mailto:davidleepub@gmail.com)。

## 1. 无需账号学习
应用提供内置韩语课程、可选韩文字母基础、测验、已保存表达复习和活动徽章。不要求账号，也不运营开发者学习数据服务器。开发者不会通过分析或崩溃报告后台接收本地学习记录。但广告、Android 语音、备份服务和您打开的网站可独立处理信息。

## 2. 设备内的记录
保存课程及表达标识、学习位置、完成次数及日期、练习答案和进度、复习记录、学习及复习日期，以及语言、声音、速度、自动播放、首页助手设置。还保存广告奖励解锁、广告暂停时间和助手问候及轮换记录。旧安装可能保留每日目标设置，当前设置界面已不提供该功能。应用介绍徽章仅记录打开 Android 分享面板，不代表消息已发送或送达。数据保存在应用私有数据库或设置中，用于学习、继续学习、设置和奖励，不上传至开发者学习服务器。

## 3. 可选录音练习
仅在选择录音时请求麦克风权限；可拒绝并使用其他学习功能。录音保存在应用私有文件夹供回放，同一练习重新录音会覆盖旧录音。不上传至开发者、广告 SDK 或 AI 服务，不做语音识别或自动发音评分。请勿未经允许录制他人声音。当前无专门录音删除按钮；清除应用存储或卸载会删除该安装中的录音。

## 4. 内置 MP3 与 Android TTS
MP3 播放应用内置韩语音频，不向开发者语音服务器发送课程文字。可切换设备 TTS；缺少 MP3 时和可选韩文字母指南使用设备 TTS。应用把课程文字交给已安装的 Android 语音合成引擎。声音和网络要求取决于引擎及所选声音；部分可离线使用，声音数据下载、联网语音和诊断可能涉及提供商服务及政策。练习录音不传给语音引擎。安装的应用不使用开发者的 Google Cloud TTS、fal.ai 或 ElevenLabs API 密钥生成语音；声音名称和开发样本不表示这些云 API 在应用内运行。

## 5. 广告及隐私选择
Unity 版本包含 Unity Ads SDK 4.16.6、Google Mobile Ads SDK 25.5.0 和 Google UMP。两家提供横幅和可选奖励广告。通过隐私条件且两个 SDK 均就绪时，首次请求约按 Unity 80%、Google 20% 选择；加载失败可向另一家已就绪服务切换一次。仅一家就绪时使用该家。这是请求分配，不保证实际展示比例；旧版可能仅用 Google。
广告 SDK 及合作伙伴可为广告、衡量、防滥用处理 IP 地址、推断的大致位置、设备或广告标识、交互及诊断信息。应用不请求 GPS、通讯录或照片库。通过 UMP 获取同意信息，按其是否允许请求广告的结果控制初始化。Unity 开发者隐私同意标志为 false，应用不声称用户已同意个性化 Unity 广告。UMP 要求时，设置中显示广告隐私选项；可用表单取决于 Google 配置及地区。也可使用 Android 广告 ID 设置。暂停横幅不保证所有 SDK 处理停止。
完成可选奖励可暂停横幅2小时；另一奖励用于解锁应用提供的额外课程包。奖励本地保存，并非付费购买、现金或可转让账号权益，能否获得取决于广告服务及成功完成。
Google 表示 SDK 传输使用 TLS。Google、Unity 及其伙伴按各自政策处理和保留广告数据，可能在境外处理；请查看下方官方政策及披露。应用不会把本地学习记录和录音附加到广告请求。
Unity 数据安全披露还列出 SDK／用户标识、购买历史信息和广告交互；这不表示应用索取姓名、邮箱、银行或卡信息或提供内购。应用不向 Unity 发送开发者账号资料或购买事件。广告及归因处理不同于本地学习奖励。Unity 还说明可选 Acquire Optimization 启用时的应用使用时间信息。

较新版本可通过经过验证的远程设置启用或停用广告提供方。初始仅启用 Unity，停用 AdMob；80:20 的选择比例仅在两者均启用且就绪时适用。应用回到前台时，最多每6小时通过 HTTPS 从 GitHub Pages 获取一次带签名的公开设置文件。应用不会在此请求中附加学习记录、录音或广告标识符，但托管方会收到 IP 地址等连接信息。离线时无限期保留最后一次验证通过的设置。广告诊断仅写入设备的 Android 日志，应用不会上传这些日志。

## 6. Android 备份及设备迁移
自动备份已启用，规则包含数据库、共享首选项和设置 DataStore。根据设备及账号设置，系统可通过其备份商备份学习和设置数据。规则将录音文件夹排除于云备份，但包含在设备到设备迁移中。实际行为取决于 Android、设备和提供商。应用没有自建云同步或手动学习备份导出。请用设备／账号备份控制管理云副本，开发者不管理这些副本。清除本地数据不保证历史系统备份已删除；重装或迁移后可恢复。

## 7. 保留、删除及安全
本地数据保留至通过项目控件删除、替换、清除存储或卸载。取消保存表达仅移除卡片关联，不删除已完成练习历史。可通过 Android 设置 → 应用 → Workplace Korean → 存储 → 清除存储，或卸载删除本地数据，解锁和设置也会删除，但仍受系统恢复影响。备份及声音数据由对应服务设置管理。开发者不能远程查看或删除仅在设备上的数据。使用 Android 私有存储不代表提供额外端到端加密或保证受侵设备安全。广告数据保留／删除由广告服务管理。

## 8. 链接、分享、支持及受众
可选韩文资源、政策页、语音提供商和下载链接打开独立服务，可能按其政策接收请求和设备信息。本文使用 GitHub Pages，GitHub 可按其隐私声明处理 IP 等请求信息；它不是学习后台。介绍分享仅把预设介绍文交给 Android 分享面板中选择的应用，不附录音或学习历史；该应用可按自身政策传输。支持邮件会让我们收到您的地址及主动提供的信息，仅用于答复；请勿发送密码或不必要的私人录音。应用面向成年职场学习者，不以儿童为对象，不收集应用内年龄档案。

## 9. 联系与更新
问题、隐私请求或错误请联系上方邮箱并注明 Workplace Korean。处理方式变化时更新日期，重要变化会通过适当的应用或版本信息说明。
