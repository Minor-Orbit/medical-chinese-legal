# 개인정보처리방침

시행일: 2026년 10월 11일.

대상 앱: **Workplace Korean: Learn Korean(한국일터, Practical Workplace Korean)**. Android 패키지: `com.minororbit.workplacekorean`. 개발자 및 문의 연락처: **[davidleepub@gmail.com](mailto:davidleepub@gmail.com)**. 이 문서는 이 앱에만 적용됩니다.

## 1. 회원가입 없는 학습

앱에 포함된 한국어 수업, 선택형 한글 기초, 퀴즈, 저장한 표현 복습 및 활동 배지를 제공합니다. 회원가입이나 개발자가 운영하는 학습 데이터 서버는 없습니다. 개발자는 별도 분석·오류 보고 서버를 통해 학습 기록을 전달받지 않습니다. 다만 광고, Android 음성 서비스, 운영체제 백업 및 외부 웹사이트는 아래와 같이 별도로 정보를 처리할 수 있습니다.

## 2. 기기에 저장되는 정보

수업·저장 표현 식별자, 학습 위치, 완료 횟수·일시, 연습에 사용하는 답변·진도, 복습 기록, 학습·복습일, 언어·음성·속도·자동재생·목표·도우미 설정 등을 앱의 비공개 데이터베이스나 설정 영역에 저장합니다. 광고 보상에 따른 추가 수업 팩 해제, 광고 중지 시간 및 도우미 인사·메시지 순환 기록도 저장합니다.

앱 소개 배지는 Android 공유창을 연 사실을 기록할 뿐, 실제 전송 여부나 수신자를 확인하지 않습니다. 이러한 기록은 학습·이어하기·설정·보상에 사용하며 개발자 학습 서버로 전송하지 않습니다.

## 3. 선택형 마이크 녹음

사용자가 말하기 녹음을 선택할 때 마이크 권한을 요청합니다. 거절해도 다른 학습 기능을 사용할 수 있습니다. 녹음은 앱의 비공개 recordings 폴더에 저장해 직접 들어볼 수 있으며, 같은 연습 항목에서 다시 녹음하면 이전 파일을 덮어씁니다.

앱은 녹음을 개발자, 광고 SDK 또는 AI 서비스에 업로드하지 않으며 음성 인식이나 자동 발음 평가를 수행하지 않습니다. 타인의 동의 없이 녹음하지 마세요. 현재 버전에는 별도 녹음 삭제 버튼이 없으며, 앱 저장공간 초기화 또는 삭제로 해당 설치의 녹음을 제거할 수 있습니다.

## 4. Android 음성 읽기

수업의 텍스트를 설치된 Android TTS 엔진에 전달해 읽습니다. 제공 음성과 네트워크 사용 여부는 엔진·선택한 음성에 따라 달라집니다. 오프라인 음성도 있지만 음성 다운로드, 네트워크 음성 및 서비스 진단 정보는 해당 제공자의 정책에 따라 처리될 수 있습니다. 연습 녹음을 TTS 엔진에 전달하지 않습니다.

설치된 앱에는 개발자 Google Cloud TTS·fal.ai·ElevenLabs API 키를 이용한 음성 생성 기능이 없습니다. 개발 과정의 음성 샘플이나 후보 이름이 앱 내부의 해당 API 호출을 뜻하지 않습니다.

## 5. Google 광고와 개인정보 선택

Google Mobile Ads SDK **25.5.0**과 User Messaging Platform(UMP)을 사용해 배너 및 선택형 보상 광고를 제공합니다. Google과 광고 파트너는 IP 주소·추정한 대략적 위치, 기기·계정·광고 식별자, 상호작용 및 진단 정보를 광고·측정·부정 사용 방지 목적으로 처리할 수 있습니다. 앱은 GPS 위치·연락처·사진 보관함 권한을 요청하지 않습니다.

UMP로 동의 정보를 요청하고 Google의 광고 요청 가능 결과에 따라 광고 초기화를 진행합니다. UMP에서 필요하다고 판단하면 설정에 광고 개인정보 선택 항목을 표시합니다. 제공 양식·선택지는 지역과 Google 설정에 따라 다르며 Android의 광고 ID 관리도 사용할 수 있습니다. 배너 광고 중지가 모든 SDK 정보 처리를 중단한다는 뜻은 아닙니다.

보상을 획득한 광고는 배너를 2시간 중지하거나, 별도 광고로 앱에서 제공하는 추가 수업 팩을 해제합니다. 보상은 기기 내 기록이며 결제 상품·현금·다른 계정으로 이전 가능한 권리가 아닙니다. 광고 제공 여부와 정상적인 보상 완료에 따라 적용됩니다.

Google은 광고 SDK 전송에 TLS 암호화를 사용한다고 안내합니다. Google·파트너의 정보는 해당 정책에 따라 보관·처리되며 국외 처리가 발생할 수 있습니다. [Google 개인정보처리방침](https://policies.google.com/privacy), [광고 안내](https://policies.google.com/technologies/ads), [SDK 정보 공개](https://developers.google.com/admob/android/privacy/play-data-disclosure)를 참고하세요.

## 6. Android 백업과 기기 이전

Android 자동 백업을 활성화한 앱입니다. 백업 규칙은 데이터베이스·공유 설정·DataStore 설정을 포함하므로 기기·계정 설정에 따라 운영체제의 백업 제공자가 학습·설정 정보를 보관할 수 있습니다. 설정된 클라우드 백업에는 recordings 폴더를 포함하지 않지만, 기기 간 이전에는 녹음을 포함합니다. 실제 동작은 Android 버전·기기·제공자에 따라 다릅니다.

개발자 자체 클라우드 동기화나 수동 학습 백업 내보내기는 제공하지 않습니다. 운영체제 백업 사본은 기기·계정의 백업 설정에서 관리해야 합니다. 로컬 저장공간 초기화가 기존 백업 사본 삭제를 보장하지 않으며, 재설치·기기 이전 과정에서 복원될 수 있습니다.

## 7. 보관·삭제·보안

로컬 정보는 지원되는 항목 삭제, 덮어쓰기, 저장공간 초기화 또는 앱 삭제 전까지 보관됩니다. 표현 저장을 해제해도 학습 완료 기록까지 삭제되는 것은 아닙니다. 전체 로컬 정보는 Android 설정 → 앱 → Workplace Korean → 저장공간 → 저장공간 삭제, 또는 앱 삭제로 제거할 수 있습니다. 해제 보상·설정도 제거되지만 운영체제 백업으로 이후 복원될 수 있습니다. 백업 사본과 TTS 음성 데이터는 각각 제공자의 설정에서 관리하세요.

개발자는 기기에만 저장된 정보를 원격으로 조회·삭제할 수 없습니다. Android 비공개 저장공간을 사용하지만 추가 종단간 암호화나 침해된 기기에서의 완전한 보호를 보장하지 않습니다. 광고 제공자가 처리한 정보의 보관·삭제는 해당 서비스 정책에 따릅니다.

앱 소개 공유는 사용자가 선택한 앱에 미리 작성한 소개 텍스트를 전달합니다. 녹음·학습 기록을 첨부하지 않으며 수신 앱의 메시지 처리는 해당 정책에 따릅니다.

이메일 문의 시 주소와 직접 보내신 내용을 받아 답변에 사용합니다. 비밀번호나 불필요한 개인 녹음을 보내지 마세요. 성인 직장 학습자를 위한 앱이며 아동 대상 서비스로 설계하지 않았고 앱 내 연령 프로필을 수집하지 않습니다.
