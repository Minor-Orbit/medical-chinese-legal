# Нууцлалын бодлого

Хүчин төгөлдөр огноо: 2026 оны 10 сарын 24. Зөвхөн **Workplace Korean: Learn Korean (한국일터 / Practical Workplace Korean)** аппад хамаарна. Android багц: `com.minororbit.workplacekorean`. Хөгжүүлэгч/тусламж: [davidleepub@gmail.com](mailto:davidleepub@gmail.com).

## 1. Бүртгэлгүй суралцах
Солонгос хэлний суулгагдсан хичээл, сонголтот хангыл үндэс, сорил, хадгалсан хэллэг давтах, тэмдэг олгоно. Хэрэглэгчийн бүртгэл шаардахгүй. Хөгжүүлэгч сургалтын өгөгдлийн сервер ажиллуулахгүй, шинжилгээ/алдааны тайлангийн системээр төхөөрөмжийн сургалтын түүх хүлээн авахгүй. Зар, Android дуу, нөөцлөлт, нээсэн гадаад сайт мэдээллийг тусад нь боловсруулж болно.

## 2. Төхөөрөмжийн бүртгэл
Хичээл/хэллэгийн ID, суралцах байрлал, дуусгасан тоо/огноо, хариулт/явц, давтлагын түүх, суралцсан/давтсан өдөр, хэл, дуу, хурд, автомат тоглуулах, туслахын тохиргоо хадгална. Зар үзсэний шагналын нээлт, зар түр зогсоох хугацаа, туслахын мэндчилгээ/ээлжийн түүх мөн хадгална. Хуучин суулгалтад өдрийн зорилго үлдэж болох ч одоогийн тохиргоонд байхгүй. Танилцуулгын тэмдэг нь Android хуваалцах самбар нээснийг л бүртгэхээс мессеж илгээсэн, хүрснийг батлахгүй. Эдгээр нь аппын хувийн сан/тохиргоонд суралцах, үргэлжлүүлэх, шагналд ашиглагдана; хөгжүүлэгчийн сургалтын серверт илгээгдэхгүй.

## 3. Сонголтот микрофон дасгал
Бичлэг сонгоход микрофоны зөвшөөрөл авна; татгалзаад бусад боломжийг ашиглаж болно. Бичлэг хувийн хавтсанд өөрөө сонсох зориулалттай; ижил дасгалыг дахин бичвэл өмнөхийг солино. Хөгжүүлэгч, зарын SDK, AI үйлчилгээнд байршуулахгүй; яриа таних, дуудлагад автомат оноо өгөхгүй. Бусдыг зөвшөөрөлгүй бүү бич. Тусгай устгах товчгүй; аппын хадгалалтыг цэвэрлэх/устгах нь тухайн суулгалтын бичлэгийг арилгана.

## 4. MP3 ба Android TTS
MP3 суулгагдсан солонгос дууг тоглуулж, текстийг хөгжүүлэгчийн дууны серверт илгээхгүй. Төхөөрөмжийн TTS сонгож болно; MP3 байхгүй болон хангылын сонголтот зааварт TTS ашиглана. Текст суулгасан Android TTS хөдөлгүүрт очно. Дуу/сүлжээ нь хөдөлгүүр, сонгосон дуунаас хамаарна; зарим нь офлайн, дуу татах, онлайн дуу, оношилгоо нь нийлүүлэгчийн үйлчилгээ/бодлогод хамаарч болно. Дасгалын бичлэг TTS-д өгөхгүй. Суулгасан апп хөгжүүлэгчийн Google Cloud TTS, fal.ai, ElevenLabs API түлхүүрээр дуу үүсгэхгүй. Дууны нэр/хөгжүүлэлтийн дээж нь эдгээр үүлэн API апп дотор ажиллахыг илэрхийлэхгүй.

## 5. Зар ба нууцлалын сонголт
Unity хувилбарт Unity Ads SDK 4.16.6, Google Mobile Ads SDK 25.5.0, Google UMP бий. Хоёр нийлүүлэгчийн баннер/сонголтот шагналт зар ашиглана. Нууцлалын нөхцөлийн дараа хоёул бэлэн бол эхний хүсэлтийг ойролцоогоор Unity 80%/Google 20% сонгоно; ачаалалт бүтэлгүйтвэл нөгөө бэлэн нийлүүлэгчийг нэг удаа оролдож болно. Нэг нь бэлэн бол түүнийг ашиглана. Энэ нь хүсэлт хуваарилалт, харуулах зарын хувь баталгаа биш; хуучин хувилбар зөвхөн Google байж болно.
SDK/түншүүд зар, хэмжилт, урвуулан ашиглахаас сэргийлэх зорилгоор IP, таамагласан ерөнхий байршил, төхөөрөмж/зарын ID, харилцан үйлдэл, оношилгоо боловсруулж болно. GPS, харилцах хаяг, зургийн сан шаардахгүй. UMP зөвшөөрлийн мэдээлэл авч, зар хүсэх боломжийн үр дүн эхлүүлэлтийг хянадаг. Unity хөгжүүлэгчийн нууцлалын зөвшөөрлийн тэмдэг false; хувийн тохируулгатай зарыг зөвшөөрсөн гэж мэдэгдэхгүй. UMP шаардвал тохиргоонд зарын нууцлалын сонголт гарна; маягт нь Google тохиргоо/бүсээс хамаарна. Android зарын ID тохиргоо мөн бий. Баннер зогсоох нь бүх SDK боловсруулалт зогсох баталгаа биш.
Олсон сонголтот шагнал баннерыг 2 цаг зогсооно; өөр шагнал нэмэлт хичээлийн багц нээнэ. Шагнал төхөөрөмжид хадгалагдана, төлбөрт худалдан авалт, бэлэн мөнгө, шилжүүлж болох дансны эрх биш. Олдоц нь зарын үйлчилгээ/амжилттай дуусгалтаас хамаарна.
Google SDK дамжуулалт TLS хэрэглэдэг гэж мэдээлдэг. Google, Unity, түншүүд өөрсдийн бодлогоор, танай улсаас гадуур ч боловсруулж/хадгалж болно; албан холбоосууд доор. Апп сургалтын түүх/бичлэгийг зарын хүсэлтэд хавсаргахгүй. Unity мэдээлэлд SDK/хэрэглэгчийн ID, худалдан авалтын түүхийн мэдээлэл, зарын харилцан үйлдэл ч багтана. Энэ нь апп нэр, имэйл, банк/карт асуух, дотоод худалдан авалт санал болгох гэсэн үг биш. Хөгжүүлэгчийн бүртгэлийн профайл/худалдан авалтын үйл явдал Unity-д илгээгдэхгүй. Зар/атрибуц нь орон нутгийн сургалтын шагналаас тусдаа. Unity сонголтот Acquire Optimization идэвхтэй үед аппын хэрэглээний хугацааг мөн тайлбарладаг.

Шинэ хувилбарт баталгаажуулсан алсын тохиргоогоор зар сурталчилгааны үйлчилгээ үзүүлэгчийг идэвхжүүлж, идэвхгүй болгож болно. Эхэндээ зөвхөн Unity идэвхтэй, AdMob идэвхгүй байна. Хоёулаа идэвхтэй, бэлэн үед л 80:20 сонголт үйлчилнэ. Апп урд талд буцаж нээгдэхэд дээд тал нь 6 цаг тутамд нэг удаа GitHub Pages-ээс HTTPS-ээр тоон гарын үсэгтэй нийтэд нээлттэй тохиргооны файл авна. Апп энэ хүсэлтэд суралцсан түүх, дууны бичлэг, зарын таних дугаар хавсаргахгүй. Харин хостингийн үйлчилгээ үзүүлэгч IP хаяг зэрэг холболтын мэдээлэл авна. Офлайн үед хамгийн сүүлд баталгаажуулсан тохиргоог хугацаагүй хадгална. Зарын оношилгоог зөвхөн төхөөрөмжийн Android бүртгэлд бичиж, апп илгээхгүй.

## 6. Нөөц ба төхөөрөмж шилжүүлэлт
Android автомат нөөц идэвхтэй; сан, shared preferences, тохиргооны DataStore орно. Төхөөрөмж/бүртгэлийн тохиргоогоор OS өөрийн нийлүүлэгчээр сургалт/тохиргоог нөөцөлж болно. Бичлэгийн хавтсыг үүлэн нөөцөөс хассан ч төхөөрөмж хоорондын шилжүүлэлтэд оруулсан. Бодит ажиллагаа Android, төхөөрөмж, нийлүүлэгчээс хамаарна. Өөрийн үүлэн синк, гараар сургалтын нөөц экспортлохгүй. Үүлэн хуулбарыг хөгжүүлэгч бус төхөөрөмж/бүртгэлээс удирдана. Локал устгал хуучин OS нөөцийг устгах баталгаа биш; дахин суулгах/шилжүүлэхэд сэргээгдэж болно.

## 7. Хадгалалт, устгал, хамгаалалт
Өгөгдөл боломжит удирдлагаар устгах, солих, хадгалалт цэвэрлэх, апп устгах хүртэл байна. Хэллэгийг хадгалалтаас гаргах нь картын холбоог л арилгана, дууссан дасгалын түүхийг биш. Android тохиргоо → Апп → Workplace Korean → Хадгалалт → Хадгалалтыг цэвэрлэх эсвэл апп устгахад локал өгөгдөл, нээлт, тохиргоо арилна; OS сэргээж болно. Нөөц/дууны өгөгдлийг тус нийлүүлэгч дээр удирдана. Хөгжүүлэгч зөвхөн төхөөрөмжийн өгөгдлийг зайнаас үзэж/устгаж чадахгүй. Android хувийн хадгалалт нэмэлт төгсгөл хоорондын шифрлэлт эсвэл халдлагад өртсөн төхөөрөмжийн хамгаалалтын амлалт биш. Зарын өгөгдлийн хадгалалт/устгал зарын үйлчилгээнд хамаарна.

## 8. Холбоос, хуваалцах, тусламж, хэрэглэгч
Хангыл материал, бодлого, дуу/татах холбоос гаднын үйлчилгээ нээж, тэд өөрсдийн бодлогоор хүсэлт/төхөөрөмжийн мэдээлэл авч болно. Баримт GitHub Pages дээр; GitHub IP/хүсэлтийг нууцлалын мэдэгдлээр боловсруулж болно, энэ сургалтын сервер биш. Танилцуулга хуваалцах нь Android самбараас сонгосон аппад бэлэн текст өгч, бичлэг/түүх хавсаргахгүй. Тэр апп өөрийн бодлогоор илгээж болно. Тусламжийн имэйлээр таны хаяг, сайн дураар өгсөн мэдээллийг хариулахад авна. Нууц үг/шаардлагагүй хувийн бичлэг бүү явуул. Апп насанд хүрсэн ажлын байрны суралцагчдад, хүүхдэд чиглээгүй; насны профайл цуглуулахгүй.

## 9. Холбоо ба шинэчлэл
Асуулт, нууцлалын хүсэлт/алдааг дээрх имэйлд Workplace Korean гэж илгээнэ үү. Практик өөрчлөгдвөл огноог шинэчилж, чухал өөрчлөлтийг зохих апп/хувилбарын мэдээллээр мэдэгдэнэ.
