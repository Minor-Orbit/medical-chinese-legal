# පෞද්ගලිකත්ව ප්‍රතිපත්තිය

බලාත්මක දිනය: 2026 ඔක්තෝබර් 24. **Workplace Korean: Learn Korean (한국일터 / Practical Workplace Korean)** සඳහා පමණි. Android පැකේජය: `com.minororbit.workplacekorean`. සංවර්ධක/සහාය: [davidleepub@gmail.com](mailto:davidleepub@gmail.com).

## 1. ගිණුමක් නැතිව ඉගෙනීම
ඇතුළත් කොරියානු පාඩම්, විකල්ප හන්ගුල් මූලික මඟපෙන්වීම, ප්‍රශ්න, සුරැකි ප්‍රකාශ පුනරාවර්තනය සහ ලාංඡන ඇත. ගිණුමක් අවශ්‍ය නැත. සංවර්ධකයා ඉගෙනුම් දත්ත සේවාදායකයක් පවත්වාගෙන නොයන අතර විශ්ලේෂණ/බිඳවැටීම් වාර්තා පද්ධතියකින් දේශීය ඉගෙනුම් ඉතිහාසය නොලබයි. දැන්වීම්, Android හඬ, උපස්ථ සහ බාහිර වෙබ් සේවා වෙනම තොරතුරු සැකසිය හැක.

## 2. උපාංගයේ සටහන්
පාඩම්/ප්‍රකාශ හඳුනාගැනීම්, ඉගෙනුම් ස්ථානය, අවසන් කළ ගණන/දින, පිළිතුරු/ප්‍රගතිය, පුනරාවර්තන සටහන්, ඉගෙනුම්/පුනරාවර්තන දින, භාෂාව, හඬ, වේගය, ස්වයං ධාවනය සහ සහායක සැකසුම් තබයි. දැන්වීම් ත්‍යාගයෙන් විවෘත වූ අන්තර්ගතය, දැන්වීම් විරාම වේලාව සහ සහායක ආචාර/මාරු සටහන් ද තබයි. පැරණි ස්ථාපනයක දෛනික ඉලක්කය තිබිය හැකි නමුත් වත්මන් සැකසුමේ එය නැත. හඳුන්වාදීමේ ලාංඡනය Android බෙදාගැනීමේ පැනලය විවෘත කළ බව පමණක් සටහන් කරයි; පණිවිඩයක් යැවූ/ලැබුණු බව නොවේ. මේවා යෙදුමේ පෞද්ගලික දත්ත සමුදායේ/සැකසුම්වල ඉගෙනීමට, නැවත ඇරඹීමට හා ත්‍යාගයට තබයි. සංවර්ධක ඉගෙනුම් සේවාදායකයට උඩුගත නොකරයි.

## 3. විකල්ප මයික්‍රෆෝන පුහුණුව
පටිගත කිරීම තෝරන විට මයික් අවසරය ඉල්ලයි; ප්‍රතික්ෂේප කර අනෙක් කොටස් භාවිත කළ හැක. නැවත ඇසීමට පෞද්ගලික ෆෝල්ඩරයේ පටිගත කරයි; එකම පුහුණුව නැවත පටිගත කිරීමෙන් පෙර එක මාරු වේ. සංවර්ධක, දැන්වීම් SDK හෝ AI වෙත උඩුගත නොකරයි; හඬ හඳුනාගැනීම හෝ ස්වයංක්‍රීය උච්චාරණ ලකුණු නැත. අවසර නැතිව අන් අය පටිගත නොකරන්න. වෙන් වූ පටිගත කිරීම් මකාදැමීමේ බොත්තමක් නැත; යෙදුම් ගබඩාව හිස් කිරීම/අස්ථාපනය එම ස්ථාපනයේ පටිගත කිරීම් මකයි.

## 4. MP3 සහ Android TTS
MP3 යෙදුමේ ඇති කොරියානු හඬ ධාවනය කරයි; පාඩම් පෙළ සංවර්ධක හඬ සේවාදායකයට නොයවයි. උපාංග TTS තෝරාගත හැක; MP3 නැති විට සහ විකල්ප හන්ගුල් මඟපෙන්වීමේ උපාංග TTS යොදාගනී. පෙළ ස්ථාපිත Android TTS එන්ජිමට දෙයි. හඬ/ජාල අවශ්‍යතාව එන්ජිම හා හඬ අනුව වෙනස්ය. සමහර හඬ නොබැඳිව ක්‍රියා කරයි; හඬ දත්ත බාගැනීම, මාර්ගගත හඬ හා දෝෂ විනිශ්චය සැපයුම්කරුගේ සේවා/ප්‍රතිපත්ති යටතේ විය හැක. පුහුණු පටිගත කිරීම් TTSට නොදෙයි. ස්ථාපිත යෙදුම සංවර්ධකගේ Google Cloud TTS, fal.ai හෝ ElevenLabs API යතුරු යොදා හඬ සාදන්නේ නැත. හඬ නාම/සංවර්ධන සාම්පල එම ක්ලවුඩ් API යෙදුම තුළ ක්‍රියා කරන බව නොකියයි.

## 5. දැන්වීම් හා පෞද්ගලිකත්ව තේරීම්
Unity අනුවාදයේ Unity Ads SDK 4.16.6, Google Mobile Ads SDK 25.5.0 සහ Google UMP ඇත. දෙපාර්ශ්වයෙන් බැනර්/විකල්ප ත්‍යාග දැන්වීම් ඇත. පෞද්ගලිකත්ව කොන්දේසි පසු දෙකම සූදානම් නම් මුල් ඉල්ලීම දළ වශයෙන් Unity 80%/Google 20% තෝරයි; පැටවීම අසාර්ථක නම් අනෙක් සූදානම් සේවාවට එක් වරක් මාරු විය හැක. එකක් පමණක් සූදානම් නම් එය භාවිත වේ. මෙය ඉල්ලීම් බෙදීමක් මිස ප්‍රදර්ශන ප්‍රතිශත පොරොන්දුවක් නොවේ; පැරණි අනුවාද Google පමණක් විය හැක.
SDK/හවුල්කරුවන් දැන්වීම්, මිනුම් හා අනිසි භාවිත වැළැක්වීමට IP, අනුමාන සාමාන්‍ය පිහිටීම, උපාංග/දැන්වීම් හැඳුනුම්, අන්තර්ක්‍රියා හා විනිශ්චය දත්ත සැකසිය හැක. GPS, සම්බන්ධතා හෝ ඡායාරූප ගබඩාව ඉල්ලන්නේ නැත. UMP එකඟතා තොරතුරු ඉල්ලයි; දැන්වීම් ඉල්ලීමට හැකි ප්‍රතිඵලය SDK ආරම්භය පාලනය කරයි. Unity සංවර්ධක පෞද්ගලිකත්ව එකඟතා සලකුණු false ය; පුද්ගලීකරණ දැන්වීම් සඳහා එකඟ වූ බව නොකියයි. UMP අවශ්‍ය කළ විට සැකසුමේ දැන්වීම් පෞද්ගලිකත්ව තේරීම් පෙන්වයි; ආකෘති Google සැකසුම්/කලාපය අනුවය.
