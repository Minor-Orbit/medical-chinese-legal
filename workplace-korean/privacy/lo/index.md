# ນະໂຍບາຍຄວາມເປັນສ່ວນຕົວ

ມີຜົນ: 24 ຕຸລາ 2026. ໃຊ້ສະເພາະ **Workplace Korean: Learn Korean (한국일터 / Practical Workplace Korean)**. ແພັກເກັດ Android: `com.minororbit.workplacekorean`. ຜູ້ພັດທະນາ/ຊ່ວຍເຫຼືອ: [davidleepub@gmail.com](mailto:davidleepub@gmail.com).

## 1. ຮຽນໂດຍບໍ່ມີບັນຊີ
ມີບົດຮຽນເກົາຫຼີໃນແອັບ, ພື້ນຖານຮັນກຶລເສີມ, ຄຳຖາມ, ທົບທວນປະໂຫຍກບັນທຶກ ແລະ ຫຼຽນ. ບໍ່ຕ້ອງມີບັນຊີ; ຜູ້ພັດທະນາບໍ່ມີເຊີບເວີຂໍ້ມູນຮຽນ ແລະ ບໍ່ຮັບປະຫວັດໃນເຄື່ອງຜ່ານການວິເຄາະ/ລາຍງານຂັດຂ້ອງ. ໂຄສະນາ, ສຽງ Android, ສຳຮອງ ແລະ ເວັບນອກອາດຈັດການຂໍ້ມູນແຍກຕ່າງຫາກ.

## 2. ບັນທຶກໃນເຄື່ອງ
ເກັບລະຫັດບົດ/ປະໂຫຍກ, ຈຸດຮຽນ, ຈຳນວນ/ວັນທີຈົບ, ຄຳຕອບ/ຄວາມຄືບໜ້າ, ປະຫວັດທົບທວນ, ວັນຮຽນ/ທົບທວນ, ພາສາ, ສຽງ, ຄວາມໄວ, ອັດຕະໂນມັດ ແລະ ຕົວຊ່ວຍ. ເກັບການປົດລັອກລາງວັນໂຄສະນາ, ເວລາພັກໂຄສະນາ ແລະ ການທັກ/ສະຫຼັບຕົວຊ່ວຍ. ຮຸ່ນເກົ່າອາດເຫຼືອເປົ້າໝາຍລາຍວັນ ແຕ່ຕັ້ງຄ່າປັດຈຸບັນບໍ່ມີ. ຫຼຽນແນະນຳແອັບບັນທຶກພຽງເປີດແຜງແບ່ງປັນ Android, ບໍ່ແມ່ນສົ່ງຫຼືຮອດຜູ້ຮັບ. ຂໍ້ມູນຢູ່ຖານຂໍ້ມູນ/ຕັ້ງຄ່າສ່ວນຕົວເພື່ອຮຽນ, ຮຽນຕໍ່ ແລະ ລາງວັນ; ບໍ່ອັບໂຫຼດໄປເຊີບເວີຜູ້ພັດທະນາ.

## 3. ອັດສຽງຕາມສະໝັກໃຈ
ຂໍສິດໄມເມື່ອເລືອກອັດສຽງ; ປະຕິເສດແລະໃຊ້ສ່ວນອື່ນໄດ້. ເກັບໃນໂຟນເດີສ່ວນຕົວເພື່ອຟັງຄືນ; ອັດລາຍການເດີມໃໝ່ຈະແທນໄຟລ໌ເກົ່າ. ບໍ່ສົ່ງໃຫ້ຜູ້ພັດທະນາ, SDK ໂຄສະນາ ຫຼື AI; ບໍ່ຮູ້ຈຳສຽງຫຼືໃຫ້ຄະແນນອອກສຽງອັດຕະໂນມັດ. ຢ່າອັດຄົນອື່ນໂດຍບໍ່ອະນຸຍາດ. ບໍ່ມີປຸ່ມລຶບສຽງແຍກ; ລ້າງພື້ນທີ່ແອັບຫຼືຖອນຕິດຕັ້ງຈະລຶບສຽງຂອງການຕິດຕັ້ງນັ້ນ.

## 4. MP3 ແລະ Android TTS
MP3 ຫຼິ້ນສຽງເກົາຫຼີທີ່ມາກັບແອັບ ບໍ່ສົ່ງຂໍ້ຄວາມໄປເຊີບເວີສຽງຜູ້ພັດທະນາ. ເລືອກ TTS ເຄື່ອງໄດ້; ຂາດ MP3 ແລະ ຄູ່ມືຮັນກຶລເສີມໃຊ້ TTS ເຄື່ອງ. ສົ່ງຂໍ້ຄວາມໃຫ້ເອັນຈິນ Android TTS ທີ່ຕິດຕັ້ງ. ສຽງ/ເຄືອຂ່າຍຂຶ້ນກັບເອັນຈິນແລະສຽງ; ບາງສຽງອອບລາຍ, ການດາວໂຫຼດສຽງ, ສຽງອອນລາຍ ແລະ ວິນິດໄສອາດໃຊ້ບໍລິການ/ນະໂຍບາຍຜູ້ໃຫ້. ບໍ່ສົ່ງສຽງຝຶກໃຫ້ TTS. ແອັບບໍ່ໃຊ້ຄີ Google Cloud TTS, fal.ai ຫຼື ElevenLabs API ຂອງຜູ້ພັດທະນາສ້າງສຽງ. ຊື່ສຽງ/ຕົວຢ່າງພັດທະນາບໍ່ໝາຍວ່າ API ຄລາວເຮັດວຽກໃນແອັບ.

## 5. ໂຄສະນາແລະທາງເລືອກສ່ວນຕົວ
ຮຸ່ນ Unity ມີ Unity Ads SDK 4.16.6, Google Mobile Ads SDK 25.5.0 ແລະ Google UMP. ສອງຜູ້ໃຫ້ມີແບນເນີແລະໂຄສະນາລາງວັນເສີມ. ຫຼັງຜ່ານເງື່ອນໄຂສ່ວນຕົວ ແລະ ສອງ SDK ພ້ອມ, ຄຳຂໍທຳອິດເລືອກປະມານ Unity 80%/Google 20%; ໂຫຼດບໍ່ສຳເລັດອາດລອງອີກຝ່າຍທີ່ພ້ອມໜຶ່ງຄັ້ງ. ຖ້າພ້ອມຝ່າຍດຽວໃຊ້ຝ່າຍນັ້ນ. ເປັນການແບ່ງຄຳຂໍ ບໍ່ຮັບປະກັນອັດຕາສະແດງ; ຮຸ່ນເກົ່າອາດມີ Google ຢ່າງດຽວ.
SDK/ຄູ່ຮ່ວມອາດປະມວນ IP, ຕຳແໜ່ງທົ່ວໄປທີ່ຄາດ, ລະຫັດເຄື່ອງ/ໂຄສະນາ, ປະຕິສຳພັນ ແລະ ວິນິດໄສເພື່ອໂຄສະນາ, ວັດຜົນ ແລະ ປ້ອງກັນໃຊ້ຜິດ. ບໍ່ຂໍ GPS, ລາຍຊື່ ຫຼື ຄັງຮູບ. UMP ຂໍຂໍ້ມູນຍິນຍອມ ແລະ ຜົນວ່າຂໍໂຄສະນາໄດ້ຄວບຄຸມເລີ່ມ SDK. ທຸງຍິນຍອມ Unity ຝ່າຍຜູ້ພັດທະນາເປັນ false, ບໍ່ຢືນຢັນຍິນຍອມໂຄສະນາສະເພາະບຸກຄົນ. UMP ກຳນົດເມື່ອໃດຈຶ່ງສະແດງທາງເລືອກໃນຕັ້ງຄ່າ; ແບບຟອມຂຶ້ນກັບ Google/ພາກພື້ນ. ມີການຄວບຄຸມ ID ໂຄສະນາ Android ເຊັ່ນກັນ. ພັກແບນເນີບໍ່ຮັບປະກັນຢຸດ SDK ທຸກຢ່າງ.
ລາງວັນທີ່ໄດ້ສຳເລັດພັກແບນເນີ 2 ຊົ່ວໂມງ; ອີກລາງວັນປົດແພັກບົດເສີມ. ເກັບໃນເຄື່ອງ ບໍ່ແມ່ນຊື້, ເງິນ ຫຼື ສິດບັນຊີໂອນໄດ້; ຂຶ້ນກັບບໍລິການໂຄສະນາແລະເຮັດສຳເລັດ.
Google ລະບຸ SDK ສົ່ງດ້ວຍ TLS. Google, Unity ແລະ ຄູ່ຮ່ວມເກັບ/ປະມວນຕາມນະໂຍບາຍຕົນ ອາດຢູ່ນອກປະເທດ; ເບິ່ງລິ້ງທາງການລຸ່ມນີ້. ແອັບບໍ່ແນບປະຫວັດ/ສຽງຝຶກໃນຄຳຂໍໂຄສະນາ. Unity ລະບຸ SDK/ຜູ້ໃຊ້ ID, ປະຫວັດຊື້ ແລະ ປະຕິສຳພັນໂຄສະນາ; ບໍ່ໝາຍວ່າແອັບຂໍຊື່, ອີເມວ, ທະນາຄານ/ບັດ ຫຼື ມີຊື້ໃນແອັບ. ບໍ່ສົ່ງໂປຣໄຟລ໌ບັນຊີຜູ້ພັດທະນາ/ເຫດການຊື້ໃຫ້ Unity. ໂຄສະນາ/ການລະບຸທີ່ມາແຍກຈາກລາງວັນຮຽນ. Unity ອະທິບາຍເວລາໃຊ້ແອັບເມື່ອເປີດ Acquire Optimization ເສີມ.

**2026-10-28** — ໃນລຸ້ນໃໝ່ ການຕັ້ງຄ່າທາງໄກທີ່ກວດສອບແລ້ວສາມາດເປີດ ຫຼື ປິດຜູ້ໃຫ້ບໍລິການໂຄສະນາໄດ້. ເບື້ອງຕົ້ນເປີດພຽງ Unity ແລະປິດ AdMob; ອັດຕາເລືອກ 80:20 ໃຊ້ເມື່ອທັງສອງເປີດ ແລະພ້ອມເທົ່ານັ້ນ. ເມື່ອແອັບກັບມາຢູ່ດ້ານໜ້າ ຈະດຶງໄຟລ໌ການຕັ້ງຄ່າສາທາລະນະທີ່ມີລາຍເຊັນດິຈິຕອນຈາກ GitHub Pages ຜ່ານ HTTPS ຢ່າງຫຼາຍໜຶ່ງຄັ້ງທຸກ 6 ຊົ່ວໂມງ. ແອັບບໍ່ແນບປະຫວັດການຮຽນ, ສຽງບັນທຶກ ຫຼືລະຫັດໂຄສະນາໃນຄຳຂໍນີ້; ຜູ້ໃຫ້ບໍລິການໂຮສຕິງໄດ້ຮັບຂໍ້ມູນການເຊື່ອມຕໍ່ ລວມທັງທີ່ຢູ່ IP. ເມື່ອອອບລາຍ ຈະເກັບການຕັ້ງຄ່າທີ່ກວດສອບຄັ້ງຫຼ້າສຸດໄວ້ໂດຍບໍ່ມີວັນໝົດອາຍຸ. ຂໍ້ມູນກວດຫາບັນຫາໂຄສະນາບັນທຶກໃນ Android log ຂອງອຸປະກອນເທົ່ານັ້ນ ແລະແອັບບໍ່ອັບໂຫຼດຂໍ້ມູນນີ້.

## 6. ສຳຮອງແລະຍ້າຍເຄື່ອງ
ເປີດ Android ສຳຮອງອັດຕະໂນມັດ ລວມຖານຂໍ້ມູນ, shared preferences ແລະ DataStore ຕັ້ງຄ່າ. ຕາມຄ່າເຄື່ອງ/ບັນຊີ OS ອາດສຳຮອງຂໍ້ມູນຮຽນ/ຕັ້ງຄ່າຜ່ານຜູ້ໃຫ້. ກົດບໍ່ລວມໂຟນເດີສຽງໃນຄລາວ ແຕ່ລວມໃນການຍ້າຍເຄື່ອງຫາເຄື່ອງ. ຈິງຂຶ້ນກັບ Android, ເຄື່ອງ ແລະ ຜູ້ໃຫ້. ບໍ່ມີຄລາວຊິງກ໌ເອງຫຼືສົ່ງອອກສຳຮອງຮຽນດ້ວຍມື. ຈັດການຄລາວຜ່ານເຄື່ອງ/ບັນຊີ ບໍ່ແມ່ນຜູ້ພັດທະນາ. ລ້າງໃນເຄື່ອງບໍ່ຮັບປະກັນລຶບ OS ສຳຮອງເກົ່າ; ອາດກັບມາເມື່ອຕິດຕັ້ງໃໝ່/ຍ້າຍ.

## 7. ເກັບ, ລຶບ ແລະ ປອດໄພ
ຂໍ້ມູນຢູ່ຈົນລຶບດ້ວຍຕົວຄວບຄຸມ, ແທນທີ່, ລ້າງ ຫຼື ຖອນແອັບ. ຍົກເລີກບັນທຶກປະໂຫຍກລຶບພຽງຄວາມເຊື່ອມບັດ ບໍ່ແມ່ນປະຫວັດຝຶກຈົບ. Android ຕັ້ງຄ່າ → ແອັບ → Workplace Korean → ພື້ນທີ່ → ລ້າງຂໍ້ມູນ ຫຼື ຖອນຈະລຶບຂໍ້ມູນ/ປົດລັອກ/ຕັ້ງຄ່າ ແຕ່ OS ອາດກູ້. ຈັດການສຳຮອງ/ສຽງຜ່ານຜູ້ໃຫ້. ຜູ້ພັດທະນາບໍ່ສາມາດເບິ່ງ/ລຶບທາງໄກຂໍ້ມູນທີ່ຢູ່ເຄື່ອງຢ່າງດຽວ. ພື້ນທີ່ສ່ວນຕົວ Android ບໍ່ແມ່ນຄຳຮັບປະກັນເຂົ້າລະຫັດປາຍທາງເພີ່ມຫຼືປອດໄພເຄື່ອງຖືກເຈາະ. ບໍລິການໂຄສະນາຄວບຄຸມເກັບ/ລຶບຂໍ້ມູນຕົນ.

## 8. ລິ້ງ, ແບ່ງປັນ, ຊ່ວຍເຫຼືອ ແລະ ຜູ້ໃຊ້
ວັດຖຸຮັນກຶລ, ນະໂຍບາຍ, ສຽງ/ດາວໂຫຼດເປີດບໍລິການນອກ ທີ່ອາດຮັບຂໍ້ມູນຄຳຂໍ/ເຄື່ອງຕາມນະໂຍບາຍຕົນ. ເອກະສານຢູ່ GitHub Pages; GitHub ອາດປະມວນ IP/ຄຳຂໍຕາມປະກາດສ່ວນຕົວ ບໍ່ແມ່ນເຊີບເວີຮຽນ. ແບ່ງປັນແນະນຳສົ່ງແຕ່ຂໍ້ຄວາມສຳເລັດໃຫ້ແອັບທີ່ເລືອກ ບໍ່ແນບສຽງ/ປະຫວັດ. ແອັບນັ້ນອາດສົ່ງຕາມນະໂຍບາຍຕົນ. ອີເມວຊ່ວຍເຫຼືອໃຫ້ເຮົາຮັບທີ່ຢູ່ແລະຂໍ້ມູນທີ່ທ່ານສົ່ງເພື່ອຕອບ. ຢ່າສົ່ງລະຫັດຜ່ານ/ສຽງສ່ວນຕົວບໍ່ຈຳເປັນ. ແອັບສຳລັບຜູ້ໃຫຍ່ຮຽນເພື່ອວຽກ ບໍ່ມຸ່ງເດັກ ແລະ ບໍ່ເກັບໂປຣໄຟລ໌ອາຍຸ.

## 9. ຕິດຕໍ່ແລະປ່ຽນແປງ
ຄຳຖາມ, ຄຳຂໍສ່ວນຕົວ/ຂໍ້ຜິດພາດ ອີເມວຂ້າງເທິງລະບຸ Workplace Korean. ປ່ຽນວິທີຈະປັບວັນທີ ແລະ ແຈ້ງສຳຄັນຜ່ານຂໍ້ມູນແອັບ/ຮຸ່ນທີ່ເໝາະສົມ.
