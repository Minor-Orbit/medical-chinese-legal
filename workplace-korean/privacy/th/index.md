# นโยบายความเป็นส่วนตัว

มีผลวันที่ 24 ตุลาคม 2026 ใช้เฉพาะ **Workplace Korean: Learn Korean (한국일터 / Practical Workplace Korean)** แพ็กเกจ Android `com.minororbit.workplacekorean` ผู้พัฒนา/ติดต่อ: [davidleepub@gmail.com](mailto:davidleepub@gmail.com)

## 1. เรียนโดยไม่ต้องมีบัญชี
มีบทเรียนเกาหลีในแอป พื้นฐานฮันกึลเสริม แบบทดสอบ ทบทวนประโยคที่บันทึก และเหรียญกิจกรรม ไม่ต้องมีบัญชี ผู้พัฒนาไม่มีเซิร์ฟเวอร์ข้อมูลการเรียนและไม่รับประวัติในเครื่องผ่านระบบวิเคราะห์หรือรายงานข้อขัดข้อง แต่โฆษณา บริการเสียง Android สำรองข้อมูล และเว็บไซต์ภายนอกอาจประมวลผลข้อมูลแยกกัน

## 2. ข้อมูลในเครื่อง
บันทึกรหัสบทเรียน/ประโยค ตำแหน่งเรียน จำนวนครั้ง/วันที่จบ คำตอบ/ความคืบหน้า ประวัติทบทวน วันเรียน/ทบทวน ภาษา เสียง ความเร็ว เล่นอัตโนมัติ และตัวช่วย รวมถึงการปลดล็อกจากรางวัลโฆษณา เวลาพักโฆษณา และการทักทาย/หมุนเวียนตัวช่วย การติดตั้งเก่าอาจมีเป้ารายวันค้างอยู่ แต่การตั้งค่าปัจจุบันไม่มีแล้ว เหรียญแนะนำแอปบันทึกเพียงการเปิดแผงแชร์ Android ไม่ใช่ส่งข้อความหรือส่งถึงใคร ข้อมูลอยู่ในฐานข้อมูล/ค่าตั้งส่วนตัวของแอปเพื่อเรียน เรียนต่อ ตั้งค่า และรางวัล ไม่อัปโหลดไปเซิร์ฟเวอร์การเรียนของผู้พัฒนา

## 3. ฝึกไมโครโฟนโดยสมัครใจ
ขอสิทธิ์ไมค์เมื่อเลือกอัดเสียง ปฏิเสธและใช้ส่วนอื่นได้ ไฟล์อยู่ในโฟลเดอร์ส่วนตัวเพื่อฟังตนเอง อัดรายการเดิมใหม่จะแทนไฟล์เก่า ไม่ส่งให้ผู้พัฒนา SDK โฆษณาหรือ AI ไม่มีรู้จำเสียงหรือให้คะแนนการออกเสียงอัตโนมัติ อย่าอัดผู้อื่นโดยไม่ได้รับอนุญาต รุ่นนี้ไม่มีปุ่มลบเสียงแยก การล้างพื้นที่แอปหรือถอนการติดตั้งลบเสียงของการติดตั้งนั้น

## 4. MP3 และ Android TTS
MP3 เล่นเสียงเกาหลีที่มาพร้อมแอป ไม่ส่งข้อความไปเซิร์ฟเวอร์เสียงผู้พัฒนา เลือก TTS เครื่องได้ หากไม่มี MP3 และในคู่มือฮันกึลเสริมจะใช้ TTS เครื่อง ส่งข้อความบทเรียนให้เอนจิน Android TTS ที่ติดตั้ง เสียง/ความต้องการเครือข่ายขึ้นกับเอนจินและเสียง บางเสียงออฟไลน์ ส่วนดาวน์โหลดเสียง เสียงออนไลน์และวินิจฉัยอาจใช้บริการ/นโยบายผู้ให้บริการ ไม่ส่งเสียงฝึกให้ TTS แอปที่ติดตั้งไม่ใช้คีย์ Google Cloud TTS, fal.ai หรือ ElevenLabs API ของผู้พัฒนาเพื่อสร้างเสียง ชื่อเสียง/ตัวอย่างพัฒนาไม่แปลว่า API คลาวด์ทำงานในแอป

## 5. โฆษณาและทางเลือกส่วนตัว
รุ่น Unity มี Unity Ads SDK 4.16.6, Google Mobile Ads SDK 25.5.0 และ Google UMP ใช้ทั้งสองสำหรับแบนเนอร์และโฆษณารางวัลเสริม หลังผ่านเงื่อนไขส่วนตัวและทั้งสองพร้อม คำขอแรกเลือกประมาณ Unity 80%/Google 20% ถ้าโหลดล้มเหลวอาจลองอีกเจ้าที่พร้อมหนึ่งครั้ง ถ้าพร้อมเจ้าเดียวใช้เจ้านั้น นี่คือสัดส่วนคำขอไม่ใช่รับประกันการแสดง รุ่นเก่าอาจมี Google เท่านั้น
SDK/คู่ค้าอาจประมวลผล IP ตำแหน่งทั่วไปที่อนุมาน รหัสอุปกรณ์/โฆษณา การโต้ตอบและวินิจฉัยเพื่อโฆษณา วัดผลและป้องกันใช้ผิด ไม่ขอ GPS รายชื่อหรือคลังภาพ UMP ขอข้อมูลความยินยอมและผลอนุญาตขอโฆษณาควบคุมเริ่ม SDK ธงยินยอมส่วนตัวฝั่งผู้พัฒนาของ Unity เป็น false ไม่ยืนยันว่าคุณยินยอมโฆษณาเฉพาะบุคคล เมื่อ UMP กำหนด การตั้งค่ามีทางเลือกส่วนตัวโฆษณา แบบฟอร์มขึ้นกับ Google/ภูมิภาค ยังมีการควบคุม ID โฆษณา Android การพักแบนเนอร์ไม่รับประกันว่าทุกกระบวนการ SDK หยุด
รางวัลที่ได้สำเร็จพักแบนเนอร์ 2 ชั่วโมง รางวัลแยกปลดล็อกแพ็กบทเรียนเพิ่มเติม เก็บในเครื่อง ไม่ใช่การซื้อ เงินสด หรือสิทธิ์บัญชีโอนย้ายได้ ขึ้นกับบริการโฆษณาและทำสำเร็จ
Google ระบุการส่ง SDK ใช้ TLS Google, Unity และคู่ค้าจัดการ/เก็บตามนโยบายตนและอาจอยู่นอกประเทศคุณ ดูลิงก์ทางการด้านล่าง แอปไม่แนบประวัติเรียนหรือเสียงอัดในคำขอโฆษณา การเปิดเผย Unity ยังระบุรหัส SDK/ผู้ใช้ ข้อมูลประวัติซื้อและการโต้ตอบโฆษณา ไม่หมายความว่าแอปถามชื่อ อีเมล ธนาคาร/บัตร หรือมีซื้อในแอป ไม่ส่งโปรไฟล์บัญชีผู้พัฒนาหรือเหตุการณ์ซื้อให้ Unity โฆษณา/การระบุที่มาต่างจากรางวัลเรียนในเครื่อง Unity ยังอธิบายเวลาใช้แอปเมื่อเปิด Acquire Optimization เสริม

**2026-10-28** — ในเวอร์ชันใหม่ การตั้งค่าระยะไกลที่ตรวจสอบแล้วสามารถเปิดหรือปิดผู้ให้บริการโฆษณาได้ เริ่มต้นด้วย Unity เปิดและ AdMob ปิด อัตราเลือก 80:20 ใช้เมื่อทั้งสองเปิดและพร้อมเท่านั้น เมื่อแอปกลับมาอยู่เบื้องหน้า แอปจะรับไฟล์การตั้งค่าสาธารณะที่มีลายเซ็นดิจิทัลจาก GitHub Pages ผ่าน HTTPS ไม่เกินหนึ่งครั้งทุก 6 ชั่วโมง แอปไม่แนบประวัติการเรียน เสียงบันทึก หรือรหัสโฆษณาไปกับคำขอนี้ แต่ผู้ให้บริการโฮสติ้งจะได้รับข้อมูลการเชื่อมต่อรวมถึงที่อยู่ IP ขณะออฟไลน์ แอปจะเก็บการตั้งค่าที่ตรวจสอบล่าสุดไว้โดยไม่หมดอายุ ข้อมูลวินิจฉัยโฆษณาจะบันทึกเฉพาะในบันทึก Android บนอุปกรณ์ และแอปจะไม่อัปโหลดข้อมูลนี้

## 6. สำรองและย้ายเครื่อง
เปิดสำรองอัตโนมัติ Android รวมฐานข้อมูล shared preferences และ DataStore การตั้งค่า ตามค่าเครื่อง/บัญชี OS อาจสำรองการเรียน/ตั้งค่าผ่านผู้ให้บริการของระบบ กฎไม่รวมโฟลเดอร์เสียงในสำรองคลาวด์ แต่รวมในการย้ายเครื่องถึงเครื่อง การทำงานจริงขึ้นกับ Android อุปกรณ์และผู้ให้บริการ ไม่มีคลาวด์ซิงก์ของตัวเองหรือส่งออกสำรองการเรียนด้วยตนเอง จัดการสำเนาคลาวด์ผ่านเครื่อง/บัญชี ไม่ใช่ผู้พัฒนา ล้างในเครื่องไม่รับประกันลบสำรอง OS เก่า อาจคืนมาหลังติดตั้งใหม่/ย้ายเครื่อง

## 7. ระยะเก็บ ลบ และความปลอดภัย
อยู่จนลบผ่านตัวควบคุม แทนที่ ล้างพื้นที่ หรือถอนแอป ยกเลิกบันทึกประโยคลบเพียงความเชื่อมโยงการ์ด ไม่ลบประวัติฝึกที่เสร็จ ลบผ่านตั้งค่า Android → แอป → Workplace Korean → พื้นที่เก็บ → ล้างข้อมูล หรือถอนแอป การปลดล็อก/ตั้งค่าหายด้วย แต่อาจกู้โดย OS จัดการสำรอง/ข้อมูลเสียงที่ผู้ให้บริการ ผู้พัฒนาไม่สามารถดู/ลบจากระยะไกลข้อมูลที่มีเฉพาะในเครื่อง พื้นที่ส่วนตัว Android ไม่ใช่คำรับรองเข้ารหัสปลายทางเพิ่มเติมหรือคุ้มครองเครื่องที่ถูกเจาะ บริการโฆษณาควบคุมเก็บ/ลบข้อมูลตน

## 8. ลิงก์ แชร์ ติดต่อ และกลุ่มผู้ใช้
ทรัพยากรฮันกึล นโยบาย เสียง/ดาวน์โหลดเปิดบริการนอกที่อาจรับข้อมูลคำขอ/เครื่องตามนโยบายตน เอกสารบน GitHub Pages ซึ่งอาจประมวลผล IP/คำขอตามประกาศ GitHub ไม่ใช่ระบบหลังบ้านการเรียน แชร์แนะนำส่งข้อความสำเร็จรูปให้แอปที่เลือกในแผง Android ไม่แนบเสียง/ประวัติ แอปนั้นอาจส่งตามนโยบายของตน อีเมลช่วยเหลือทำให้เราได้รับที่อยู่และข้อมูลที่คุณส่งเพื่อให้ตอบ อย่าส่งรหัสผ่านหรือเสียงส่วนตัวไม่จำเป็น แอปสำหรับผู้ใหญ่เรียนเพื่อทำงาน ไม่มุ่งเด็กและไม่เก็บโปรไฟล์อายุในแอป

## 9. ติดต่อและเปลี่ยนแปลง
คำถาม คำขอส่วนตัวหรือข้อผิดพลาด ส่งอีเมลข้างต้นและระบุ Workplace Korean เปลี่ยนวิธีปฏิบัติจะปรับวันที่ และแจ้งการเปลี่ยนสำคัญผ่านข้อมูลแอป/รุ่นที่เหมาะสม
