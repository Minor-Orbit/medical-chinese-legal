# 隱私權政策

生效日期：2026年10月24日。本政策僅適用於 **Workplace Korean: Learn Korean（한국일터／Practical Workplace Korean）**。Android 套件名稱：`com.minororbit.workplacekorean`。開發者及支援：[davidleepub@gmail.com](mailto:davidleepub@gmail.com)。

## 1. 無須帳號學習
應用程式提供內建韓語課程、選用韓文字母基礎、測驗、已儲存表達複習和活動徽章。不要求帳號，也不營運開發者學習資料伺服器。開發者不會透過分析或當機報告後台接收本機學習紀錄。但廣告、Android 語音、備份服務和您開啟的網站可獨立處理資訊。

## 2. 裝置內的紀錄
儲存課程及表達識別碼、學習位置、完成次數與日期、練習答案與進度、複習紀錄、學習與複習日期，以及語言、聲音、速度、自動播放、首頁助手設定。也儲存廣告獎勵解鎖、廣告暫停時間和助手問候及輪替紀錄。舊安裝可能保留每日目標設定，目前設定畫面已不提供此功能。應用程式介紹徽章僅記錄開啟 Android 分享面板，不代表訊息已傳送或送達。資料儲存在應用程式私有資料庫或設定中，用於學習、繼續學習、設定和獎勵，不上傳至開發者學習伺服器。

## 3. 選用錄音練習
僅在選擇錄音時要求麥克風權限；可拒絕並使用其他學習功能。錄音儲存在應用程式私有資料夾供回放，同一練習重新錄音會覆寫舊錄音。不會上傳至開發者、廣告 SDK 或 AI 服務，不做語音辨識或自動發音評分。請勿未經允許錄製他人聲音。目前無專用錄音刪除按鈕；清除應用程式儲存空間或解除安裝會刪除該安裝中的錄音。

## 4. 內建 MP3 與 Android TTS
MP3 播放應用程式內建韓語音訊，不向開發者語音伺服器傳送課程文字。可切換裝置 TTS；缺少 MP3 時和選用韓文字母指南使用裝置 TTS。應用程式把課程文字交給已安裝的 Android 文字轉語音引擎。聲音和網路要求取決於引擎及所選聲音；部分可離線使用，聲音資料下載、連網語音和診斷可能涉及提供商服務及政策。練習錄音不傳給語音引擎。安裝的應用程式不使用開發者的 Google Cloud TTS、fal.ai 或 ElevenLabs API 金鑰產生語音；聲音名稱和開發樣本不表示這些雲端 API 在應用程式內執行。

## 5. 廣告及隱私選擇
Unity 版本包含 Unity Ads SDK 4.16.6、Google Mobile Ads SDK 25.5.0 和 Google UMP。兩家提供橫幅和選用獎勵廣告。通過隱私條件且兩個 SDK 均就緒時，首次要求約按 Unity 80%、Google 20% 選擇；載入失敗可向另一家已就緒服務切換一次。僅一家就緒時使用該家。這是要求分配，不保證實際顯示比例；舊版可能僅用 Google。
廣告 SDK 及合作夥伴可為廣告、衡量、防濫用處理 IP 位址、推斷的大致位置、裝置或廣告識別碼、互動及診斷資訊。應用程式不要求 GPS、聯絡人或照片圖庫。透過 UMP 取得同意資訊，依其是否允許要求廣告的結果控制初始化。Unity 開發者隱私同意旗標為 false，應用程式不聲稱使用者已同意個人化 Unity 廣告。UMP 要求時，設定中顯示廣告隱私選項；可用表單取決於 Google 設定及地區。也可使用 Android 廣告 ID 設定。暫停橫幅不保證所有 SDK 處理停止。
完成選用獎勵可暫停橫幅2小時；另一獎勵用於解鎖應用程式提供的額外課程包。獎勵儲存於本機，並非付費購買、現金或可轉讓帳號權益，能否獲得取決於廣告服務及成功完成。
Google 表示 SDK 傳輸使用 TLS。Google、Unity 及其夥伴依各自政策處理和保留廣告資料，可能在境外處理；請查看下方官方政策及揭露。應用程式不會把本機學習紀錄和錄音附加到廣告要求。
Unity 資料安全揭露也列出 SDK／使用者識別碼、購買歷史資訊和廣告互動；這不表示應用程式索取姓名、電子郵件、銀行或卡片資訊或提供應用程式內購買。應用程式不向 Unity 傳送開發者帳號資料或購買事件。廣告及歸因處理不同於本機學習獎勵。Unity 也說明選用 Acquire Optimization 啟用時的應用程式使用時間資訊。

**2026-10-28** — 較新版本可透過經過驗證的遠端設定啟用或停用廣告提供者。初始僅啟用 Unity，停用 AdMob；80:20 的選擇比例僅在兩者均啟用且就緒時適用。應用程式回到前景時，最多每6小時透過 HTTPS 從 GitHub Pages 取得一次帶簽章的公開設定檔。應用程式不會在此請求中附加學習紀錄、錄音或廣告識別碼，但代管業者會收到 IP 位址等連線資訊。離線時無限期保留最後一次驗證通過的設定。廣告診斷僅寫入裝置的 Android 記錄，應用程式不會上傳這些記錄。

## 6. Android 備份及裝置移轉
自動備份已啟用，規則包含資料庫、共用偏好設定和設定 DataStore。依裝置及帳號設定，系統可透過其備份商備份學習和設定資料。規則將錄音資料夾排除於雲端備份，但包含在裝置對裝置移轉中。實際行為取決於 Android、裝置和提供商。應用程式沒有自建雲端同步或手動學習備份匯出。請用裝置／帳號備份控制管理雲端副本，開發者不管理這些副本。清除本機資料不保證歷史系統備份已刪除；重新安裝或移轉後可還原。

## 7. 保留、刪除及安全
本機資料保留至透過項目控制刪除、替換、清除儲存空間或解除安裝。取消儲存表達僅移除卡片關聯，不刪除已完成練習歷史。可透過 Android 設定 → 應用程式 → Workplace Korean → 儲存空間 → 清除儲存空間，或解除安裝刪除本機資料，解鎖和設定也會刪除，但仍受系統還原影響。備份及聲音資料由對應服務設定管理。開發者不能遠端查看或刪除僅在裝置上的資料。使用 Android 私有儲存空間不代表提供額外端對端加密或保證受侵裝置安全。廣告資料保留／刪除由廣告服務管理。

## 8. 連結、分享、支援及受眾
選用韓文資源、政策頁、語音提供商和下載連結開啟獨立服務，可能依其政策接收要求和裝置資訊。本文使用 GitHub Pages，GitHub 可依其隱私權聲明處理 IP 等要求資訊；它不是學習後台。介紹分享僅把預設介紹文交給 Android 分享面板中選擇的應用程式，不附錄音或學習歷史；該應用程式可依自身政策傳輸。支援郵件會讓我們收到您的位址及主動提供的資訊，僅用於答覆；請勿傳送密碼或不必要的私人錄音。應用程式面向成年職場學習者，不以兒童為對象，不收集應用程式內年齡檔案。
