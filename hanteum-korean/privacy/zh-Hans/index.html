本政策适用于 Hanteum Korean: Campus Life，包括早期测试版和提供语音练习的版本。应用没有账号系统、广告 SDK、开发者分析 SDK，也没有由开发者运营的学习数据服务器。

1. 您设备上的学习信息

书签、课程进度、练习历史、指南复选框和设置均存储在您设备的私有应用存储中。开发者不会通过该应用接收您的学习记录。

该应用已禁用自动 Android 备份，并将其数据排除在 Android 云备份和设备传输之外。您可以使用 Android 的清除存储设置或卸载应用来删除本地学习记录。

2. 消息草稿和剪贴板

消息模板使用您的输入在内存中创建临时预览。当您离开或重新创建表单时，应用程序会清除草稿。它不会将输入保存到学习记录中，也不会发送给开发者。

当您选择复制时，Android 会将预览放置到剪贴板中。您选择在哪里粘贴以及是否发送。Android、您的键盘和目的地应用程序根据其自身的设置和政策处理文本。避免输入不必要的学生 ID 或敏感个人信息。

3. 可选的麦克风访问和语音练习

在具有语音练习功能的版本中，当您选择录音时，应用程序会请求麦克风访问权限。它每次最多录制 30 秒，并将录音暂时保存在其私有缓存中，以便您可以回听。应用程序不会上传或共享录音，也不会将其用于自动评分。

您可以在语音练习中删除录音。当您更改练习表达、离开练习屏幕或切换应用程序时，应用程序会清除录音。下次打开应用程序时，它会清除任何残留文件。如果您拒绝麦克风访问权限，学习文本和示例音频将仍然可用。

4. 课程音频与 Android 文本转语音

在包含课程音频的版本中，示例录音在分发前已准备就绪，并在您的设备上播放。当包含的录音不可用时，这些版本可以使用已安装的离线韩语 Android 语音播放固定的韩语学习文本。初始试点使用 Android 文本转语音引擎作为课程音频。该引擎可能根据其自身的设置和隐私政策处理语音。

该应用程序不会在课程期间将语音录音或消息条目传递给语音引擎，也不会调用云端语音生成 API。您的 Android 语音引擎自行管理语音下载和设置。即使语音不可用，您仍可继续阅读课程。

5. 校园地图、网站及政策托管

校园地图使用与应用程序捆绑的地图数据。应用程序不会访问您的设备位置。如果您选择在外部应用程序中打开路线，该服务将依据其自身的隐私政策处理请求。

打开韩语学习网站、外部学校或信息链接，或本政策页面时，会使用您的浏览器和目的地服务，这些服务可依据其自身政策处理常规网页请求信息。

本政策托管于 GitHub Pages。GitHub 可根据 GitHub 隐私声明处理请求信息，包括 IP 地址。托管本政策并不为开发者提供应用程序学习数据后端。 GitHub Privacy Statement

6. 删除与安全

要删除所有本地应用程序记录，请使用 Android 设置 → 应用程序 → Hanteum Korean: Campus Life → 存储 → 清除存储，或卸载应用程序。此操作也会删除进度和设置。复制的消息、通过其他应用程序发送的消息以及语音引擎下载的内容，必须在相应服务中单独管理。

开发者无法远程获取或仅存储在您设备上的记录。该应用使用 Android 私有应用存储；未声称使用额外的端到端加密。

7. 支持与政策变更

如果您通过电子邮件联系支持服务，我们将收到您的电子邮件地址以及您选择发送的信息。我们使用这些信息来回复并解决您的请求，并在需要时保留通信记录以满足相关义务。您可以通过联系同一地址请求删除，但需遵守上述义务。请标识 Hanteum Korean: Campus Life，并避免发送密码、学生证号或不必要的个人信息。

当我们的信息处理方式发生变化时，我们将更新本政策及其生效日期。
