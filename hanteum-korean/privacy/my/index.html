ဤမူဝါဒသည် Hanteum: တက္ကသိုလ်သုံး ကိုရီးယားဘာသာ ၏ အစမ်းဗားရှင်းနှင့် အသံလေ့ကျင့်နိုင်သည့် ဗားရှင်းများအတွက် အကျုံးဝင်သည်။ အက်ပ်တွင် အကောင့်စနစ်၊ အက်ပ်ဖန်တီးသူ၏ သုံးစွဲမှု ဆန်းစစ်ရေး SDK နှင့် သင်ယူမှုဒေတာကို လက်ခံသည့် ဖန်တီးသူ၏ ဆာဗာ မရှိပါ။

၁။ သင့်စက်ပေါ်ရှိ သင်ယူမှုအချက်အလက်

သိမ်းထားသည့် အသုံးအနှုန်းများ၊ သင်ခန်းစာတိုးတက်မှု၊ လေ့ကျင့်မှုမှတ်တမ်း၊ လမ်းညွှန်တွင် အမှတ်ခြစ်ထားသည့် အချက်များနှင့် ဆက်တင်များကို သင့်စက်ပေါ်ရှိ အက်ပ်သီးသန့် သိုလှောင်နေရာတွင် ထားရှိသည်။ ဖန်တီးသူသည် ဤအက်ပ်မှတစ်ဆင့် သင့်သင်ယူမှုမှတ်တမ်းကို လက်ခံရရှိခြင်း မရှိပါ။

အက်ပ်သည် Android ၏ အလိုအလျောက် အရန်သိမ်းမှုကို ပိတ်ထားသည်။ အက်ပ်ဒေတာကို Android ၏ အွန်လိုင်း အရန်သိမ်းမှုနှင့် စက်တစ်လုံးမှ တစ်လုံးသို့ ဒေတာပြောင်းရွှေ့မှုတွင် မထည့်ပါ။ Android ဆက်တင်တွင် အက်ပ်သိုလှောင်မှုကို ရှင်းလင်းခြင်း သို့မဟုတ် အက်ပ်ကို ဖြုတ်ခြင်းဖြင့် သင့်စက်ပေါ်ရှိ သင်ယူမှုမှတ်တမ်းကို ဖျက်နိုင်သည်။

၂။ စာမူကြမ်းနှင့် ကူးယူထားသည့် စာသား

စာရေးပုံစံများက သင်ဖြည့်သွင်းသည့် အချက်အလက်ဖြင့် ယာယီအစမ်းစာကို မမ်မိုရီထဲတွင် ပြုလုပ်ပေးသည်။ ဖောင်မှ ထွက်လျှင် သို့မဟုတ် ဖောင်ပြန်ဖွင့်လျှင် မူကြမ်းကို ရှင်းပစ်သည်။ ဖြည့်သွင်းထားသည်များကို သင်ယူမှုမှတ်တမ်းတွင် မသိမ်းသလို အက်ပ်ဖန်တီးသူဆီလည်း မပို့ပါ။

Copy ကို ရွေးလျှင် Android က အစမ်းစာကို ကူးယူစာသားသိုလှောင်ရာတွင် ထည့်ပေးသည်။ မည်သည့်နေရာတွင် ကူးထည့်မည်၊ ပို့မည် မပို့မည်ကို သင်ဆုံးဖြတ်နိုင်သည်။ Android၊ သင့်ကီးဘုတ်နှင့် စာသားလက်ခံသည့် အက်ပ်တို့က ၎င်းတို့၏ ဆက်တင်နှင့် မူဝါဒများအတိုင်း ကိုင်တွယ်သည်။ မလိုအပ်သော ကျောင်းသားမှတ်ပုံတင်နံပါတ်နှင့် အရေးကြီးသော ကိုယ်ရေးအချက်အလက်များကို မဖြည့်ပါနှင့်။

၃။ ရွေးချယ်နိုင်သော မိုက်ခရိုဖုန်းခွင့်ပြုချက်နှင့် အသံလေ့ကျင့်မှု

အသံလေ့ကျင့်နိုင်သည့် ဗားရှင်းတွင် အသံသွင်းရန် သင်ရွေးချယ်သောအခါ မိုက်ခရိုဖုန်းအသုံးပြုခွင့် တောင်းသည်။ တစ်ကြိမ်လျှင် စက္ကန့် ၃၀ အထိ အသံသွင်းနိုင်ပြီး ပြန်နားထောင်နိုင်ရန် အက်ပ်သီးသန့် ယာယီသိုလှောင်နေရာတွင် ထားသည်။ အသံဖိုင်ကို အွန်လိုင်းသို့ မတင်၊ မမျှဝေ၊ အလိုအလျောက် အမှတ်ပေးရန်လည်း မသုံးပါ။

အသံလေ့ကျင့်မှု မျက်နှာပြင်မှာ အသံဖိုင်ကို ဖျက်နိုင်သည်။ လေ့ကျင့်သည့် စကားလုံးကို ပြောင်းလျှင်၊ လေ့ကျင့်မှုမျက်နှာပြင်မှ ထွက်လျှင် သို့မဟုတ် အခြားအက်ပ်သို့ ပြောင်းလျှင် အသံဖိုင်ကို ရှင်းပစ်သည်။ ကျန်နေသည့် ဖိုင်ရှိပါက အက်ပ်ပြန်ဖွင့်သည့်အခါ ဖျက်သည်။ မိုက်ခရိုဖုန်းအသုံးပြုခွင့် မပေးလျှင်လည်း စာသားနှင့် နမူနာအသံများကို အသုံးပြုနိုင်သည်။

၄။ သင်ခန်းစာအသံနှင့် Android စာသားဖတ်ပြစနစ်

သင်ခန်းစာအသံ ပါဝင်သည့် ဗားရှင်းတွင် နမူနာအသံများကို မဖြန့်ချိမီ ပြင်ဆင်ထားပြီး သင့်စက်တွင် ဖွင့်သည်။ အသံဖိုင်တစ်ခု မပါလျှင် သတ်မှတ်ထားသည့် ကိုရီးယားစာကို သင့်စက်တွင် တပ်ဆင်ထားသော အော့ဖ်လိုင်း ကိုရီးယားအသံဖြင့် ဖတ်ပြနိုင်သည်။ အစမ်းဗားရှင်းသည် သင်ခန်းစာအတွက် Android စာသားဖတ်ပြစနစ်ကို သုံးသည်။ ထိုစနစ်က ၎င်း၏ ဆက်တင်နှင့် ကိုယ်ရေးအချက်အလက် မူဝါဒအတိုင်း စာသားကို အသံအဖြစ် ပြောင်းနိုင်သည်။

သင်ခန်းစာအတွင်း အက်ပ်သည် သင်သွင်းထားသည့် အသံ သို့မဟုတ် စာရေးပုံစံတွင် ဖြည့်သည့် စာသားကို စာသားဖတ်ပြစနစ်ထံ မပို့ပါ။ အွန်လိုင်း အသံဖန်တီးရေး API ကိုလည်း မခေါ်ပါ။ အသံဒေါင်းလုဒ်နှင့် ဆက်တင်များကို Android စာသားဖတ်ပြစနစ်က စီမံသည်။ အသံမရှိလျှင်လည်း သင်ခန်းစာကို ဆက်ဖတ်နိုင်သည်။

၅။ ကျောင်းဝင်းမြေပုံ၊ ဝဘ်ဆိုက်များနှင့် မူဝါဒ ထုတ်ပြန်ရာနေရာ

ကျောင်းဝင်းမြေပုံသည် အက်ပ်ထဲတွင် ပါပြီးသား မြေပုံဒေတာကို အသုံးပြုသည်။ အက်ပ်သည် သင့်စက်၏ တည်နေရာကို မရယူပါ။ လမ်းညွှန်ချက်ကို အခြားအက်ပ်တွင် ဖွင့်လျှင် ထိုဝန်ဆောင်မှုက ၎င်း၏ ကိုယ်ရေးအချက်အလက် မူဝါဒအတိုင်း တောင်းဆိုချက်ကို ကိုင်တွယ်သည်။

ဟန်ဂူးလ် လေ့လာရေးဝဘ်ဆိုက်၊ ကျောင်း သို့မဟုတ် အချက်အလက် လင့်ခ်၊ ဤမူဝါဒကို ဖွင့်သောအခါ သင့်ဘရောက်ဇာနှင့် သက်ဆိုင်ရာ ဝန်ဆောင်မှုကို အသုံးပြုသည်။ ၎င်းတို့၏ မူဝါဒများအတိုင်း ပုံမှန် ဝဘ်တောင်းဆိုချက် အချက်အလက်ကို ကိုင်တွယ်နိုင်သည်။

ဤမူဝါဒကို GitHub Pages ပေါ်တွင် ထုတ်ပြန်ထားသည်။ GitHub သည် ၎င်း၏ ကိုယ်ရေးအချက်အလက် ကြေညာချက်အတိုင်း IP လိပ်စာ အပါအဝင် ဝဘ်တောင်းဆိုချက် အချက်အလက်ကို ကိုင်တွယ်နိုင်သည်။ ဤစာမျက်နှာကို ထုတ်ပြန်ထားခြင်းဖြင့် အက်ပ်ဖန်တီးသူသည် သင်ယူမှုဒေတာ လက်ခံသည့် ဆာဗာကို ရရှိခြင်းမရှိပါ။ GitHub Privacy Statement

၆။ ဒေတာဖျက်ခြင်းနှင့် လုံခြုံရေး

အပ်လီကေးရှင်း၏ ဒေတာအားလုံးကို ဖျက်သိမ်းလိုပါက Android Settings → Apps → Hanteum: တက္ကသိုလ်သုံး ကိုရီးယားဘာသာ → Storage → Clear storage သို့မဟုတ် အပ်လီကေးရှင်းကို ဖျက်သိမ်းပါ။ ထိုသို့ပြုလုပ်ခြင်းသည် အဆင့်ဆင့်တိုးတက်မှုနှင့် သတ်မှတ်ချက်များကိုပါ ဖျက်သိမ်းပေးပါသည်။ ကူးယူထားသော စာများ၊ အခြားအပ်လီကေးရှင်းတစ်ခုမှ ပို့ဆောင်ထားသော စာများနှင့် အသံအင်ဂျင် ဒေါင်းလုဒ်များကို ထိုစနစ်များတွင် သီးခြားစီ စီမံခန့်ခွဲရပါမည်။

သင့်စက်ပေါ်တွင်သာ သိမ်းထားသော မှတ်တမ်းများကို အက်ပ်ဖန်တီးသူက အဝေးမှ ရယူခြင်း သို့မဟုတ် ဖျက်ခြင်း မပြုနိုင်ပါ။ အက်ပ်သည် Android ပေါ်ရှိ အက်ပ်သီးသန့် သိုလှောင်နေရာကို အသုံးပြုသည်။ End-to-end စာဝှက်စနစ် ထပ်သုံးသည်ဟု မဆိုထားပါ။

၇။ အကူအညီနှင့် မူဝါဒ အပြောင်းအလဲများ

အကူအညီတောင်းရန် အီးမေးလ်ပို့လျှင် သင့်အီးမေးလ်လိပ်စာနှင့် သင်ပို့သည့် အချက်အလက်ကို ကျွန်ုပ်တို့ လက်ခံရရှိသည်။ အကြောင်းပြန်ရန်နှင့် သင့်တောင်းဆိုချက်ကို ဖြေရှင်းရန် အသုံးပြုသည်။ ထိုရည်ရွယ်ချက်နှင့် သက်ဆိုင်ရာ တာဝန်များအတွက် လိုအပ်သရွေ့ ဆက်သွယ်စာများကို သိမ်းထားသည်။ ထိုတာဝန်များနှင့်အညီ အဆိုပါလိပ်စာသို့ ရေးသားပြီး ဖျက်ပေးရန် တောင်းဆိုနိုင်သည်။ Hanteum: တက္ကသိုလ်သုံး ကိုရီးယားဘာသာ အမည်ကို ထည့်ရေးပါ။ စကားဝှက်၊ ကျောင်းသားမှတ်ပုံတင်နံပါတ်နှင့် မလိုအပ်သော ကိုယ်ရေးအချက်အလက်များကို မပို့ပါနှင့်။

အချက်အလက် ကိုင်တွယ်ပုံ ပြောင်းလဲလျှင် ဤမူဝါဒနှင့် ၎င်းစတင်အသက်ဝင်သည့်ရက်ကို ပြင်ဆင်မည်။

ကြော်ငြာပါသော ဗားရှင်းများတွင် Google AdMob နဖူးစည်းကြော်ငြာနှင့် ဆန္ဒရှိမှ ကြည့်ရသော ဆုရဗီဒီယိုများ ပါသည်။ SDK သည် အနီးစပ်ဆုံး တည်နေရာကို ခန့်မှန်းနိုင်သည့် IP လိပ်စာ၊ နှိပ်ခြင်းနှင့် ဗီဒီယိုကြည့်ခြင်းကဲ့သို့ အသုံးပြုမှု၊ စစ်ဆေးရေးအချက်အလက်၊ Android ကြော်ငြာ ID နှင့် အက်ပ်အစု ID ကဲ့သို့ စက် သို့မဟုတ် အကောင့် အမှတ်အသားများကို စုဆောင်းမျှဝေနိုင်ပါသည်။ Google သည် ကြော်ငြာ၊ တိုင်းတာမှုနှင့် လိမ်လည်မှုကာကွယ်ရေးအတွက် သုံးပြီး ပေးပို့စဉ် ကုဒ်ဝှက်ပါသည်။ ရရှိနိုင်ပါက အက်ပ်ဆက်တင်များတွင် ကြော်ငြာ ကိုယ်ရေးလုံခြုံမှု ရွေးချယ်စရာများကို ပြောင်းနိုင်ပါသည်။ သိမ်းထားသည့် စကားများ၊ တိုးတက်မှု၊ မူကြမ်းနှင့် အသံဖိုင်များကို ကြော်ငြာ SDK ထံ မပို့ပါ။
