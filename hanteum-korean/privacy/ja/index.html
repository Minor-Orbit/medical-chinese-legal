本ポリシーは、Hanteum Korean: Campus Life（初期パイロット版および音声練習を含むバージョン）に適用されます。本アプリにはアカウントシステム、広告 SDK、開発者分析 SDK、または開発者が運営する学習データサーバーは存在しません。

1. デバイス上の学習情報

ブックマーク、レッスン進捗、練習履歴、ガイドのチェックマーク、および設定は、デバイスのプライベートアプリストレージに保存されます。開発者は、アプリを通じて学習記録を受け取りません。

本アプリは、Android の自動バックアップを無効にし、データを Android クラウドバックアップおよびデバイス転送から除外します。Android の「ストレージをクリア」設定を使用するか、アプリをアンインストールすることで、ローカルの学習記録を削除できます。

2. メッセージドラフトとクリップボード

メッセージテンプレートは、ユーザーの入力を使用してメモリ上に一時的なプレビューを作成します。アプリは、フォームを離れたり再作成したりするとドラフトをクリアします。入力は学習記録に保存されず、開発者に送信されません。

コピーを選択すると、Android はプレビューをクリップボードに配置します。貼り付け先や送信するかどうかはユーザーが選択します。Android、キーボード、宛先のアプリは、それぞれ独自の設定とポリシーに基づいてテキストを処理します。不要な学生 ID や機密の個人情報を入力しないでください。

3. オプションのマイクアクセスと音声練習

音声練習機能があるバージョンでは、アプリは録音を選択した際にマイクへのアクセスを要求します。一度に最大 30 秒を録音し、一時的にプライベートキャッシュに保持してユーザーが再生できるようにします。アプリは録音をアップロードしたり共有したりせず、自動採点にも使用しません。

Voice practice で録音は削除できます。アプリは、練習表現を変更したり、練習画面を離れたり、アプリを切り替えると録音をクリアします。アプリを再度開いたときに残っているファイルもクリアされます。マイクへのアクセスを拒否した場合でも、学習テキストと例の音声は引き続き利用可能です。

4. 授業音声と Android テキスト読み上げ

授業音声が含まれるバージョンでは、配布前にサンプル録音が準備され、お使いのデバイスで再生されます。含まれる録音が利用できない場合、インストール済みのオフライン韓国語 Android 音声を使用して、固定された韓国語学習テキストを再生できます。初期パイロットでは、Android テキスト読み上げエンジンが授業音声に使用されます。このエンジンは、独自の設定とプライバシーポリシーに従って音声処理を行う場合があります。

レッスン中に、録音した音声やメッセージの入力内容を読み上げエンジンに渡すことはありません。クラウドの音声合成 API も呼び出しません。音声のダウンロードと設定は Android の読み上げエンジンが管理します。音声を利用できない場合も、レッスンを読むことができます。

5. キャンパスマップ、ウェブサイトおよびポリシーホスティング

キャンパスマップはアプリにバンドルされた地図データを使用します。アプリはデバイスの位置情報にアクセスしません。外部アプリで経路を開く場合、そのサービスは独自のプライバシーポリシーに従ってリクエストを処理します。

ハングル学習サイト、外部の学校または情報リンク、またはこのポリシーを開く場合、ブラウザと宛先サービスが使用され、通常のウェブリクエスト情報をそれぞれのポリシーに従って処理します。

このポリシーは GitHub Pages でホストされています。GitHub は IP アドレスを含むリクエスト情報を GitHub のプライバシー声明に従って処理できます。このポリシーのホスティングは、開発者にアプリ学習データのバックエンドを提供するものではありません。 GitHub Privacy Statement

6. 削除とセキュリティ

すべてのローカルアプリ記録を削除するには、Android 設定 → アプリ → Hanteum Korean: Campus Life → ストレージ → ストレージをクリア、またはアプリをアンインストールしてください。これにより、進捗と設定も削除されます。コピーされたメッセージ、別のアプリ経由で送信したメッセージ、および音声エンジンダウンロードは、それぞれのサービスで別途管理する必要があります。

開発者は、デバイス上にのみ保存された記録を遠隔で取得または削除することはできません。本アプリは Android のプライベートアプリストレージを使用しており、追加のエンドツーエンド暗号化は主張されていません。

7. サポートとポリシーの変更

サポートにメールを送信した場合、メールアドレスと送信された情報を受信します。これを使用してご要望に応え、対応を完了させ、必要に応じて記録を保持します。同様のアドレスに連絡して削除を依頼することもできますが、上記の義務は適用されます。Hanteum Korean: Campus Life を特定し、パスワード、学生証番号、または不要な個人情報を送信しないでください。

情報の取り扱いが変わる場合は、本ポリシーと施行日を更新します。
