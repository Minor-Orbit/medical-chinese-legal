本政策適用於 Hanteum：校園韓語，包括早期測試版和提供口說練習的版本。此應用程式沒有帳號系統、廣告 SDK、開發者分析 SDK，也沒有由開發者營運的學習資料伺服器。

1. 您裝置上的學習資訊

書籤、課程進度、練習紀錄、指南勾選與設定均儲存於您裝置的私密應用程式儲存空間中。開發者不會透過本應用程式接收您的學習紀錄。

本應用程式已停用自動 Android 備份，並將其數據排除於 Android 雲端備份與裝置傳輸之外。您可以透過 Android 的清除儲存空間設定或解除安裝應用程式來移除本地學習紀錄。

2. 訊息草稿與剪貼簿

訊息範本會使用您的輸入在記憶體中建立臨時預覽。當您離開或重新建立表單時，應用程式會清除草稿。它不會將輸入儲存至學習記錄或傳送給開發者。

當您選擇複製時，Android 會將預覽放置於剪貼簿中。您決定貼上位置以及是否要發送。Android、您的鍵盤以及目標應用程式會根據各自的設定與政策處理文字。請避免輸入不必要的學生編號或敏感個人資訊。

3. 可選的麥克風存取與口語練習

在具備口語練習功能的版本中，當您選擇錄音時，應用程式會請求麥克風存取權限。它會一次錄製最多 30 秒，並將錄音暫時儲存於私人快取中，以便您回聽。應用程式不會上傳或分享該錄音，也不會用於自動評分。

您可以在口語練習中刪除錄音。當您變更練習發音、離開練習畫面或切換應用程式時，應用程式會清除錄音。下次開啟應用程式時，會清除任何剩餘檔案。若您拒絕麥克風存取權限，學習文字與範例音訊仍會保持可用。

4. 課程音訊與 Android 文字轉語音

在包含課程音訊的版本中，範例錄音會在分發前準備好，並在您的裝置上播放。當包含的錄音不可用時，這些版本可以使用已安裝的離線韓文 Android 語音來播放固定的韓文學習文字。初始測試階段使用 Android 文字轉語音引擎作為課程音訊。該引擎可能會根據其自身的設定與隱私權政策處理語音。

本應用程式不會在課程期間將語音錄音或訊息條目傳遞給語音引擎，也不會呼叫雲端語音生成 API。您的 Android 語音引擎會自行管理語音下載與設定。即使語音不可用，您仍可繼續閱讀課程。

5. 校園地圖、網站與政策託管

校園地圖使用與應用程式捆綁的地圖資料。本應用程式不會存取您的裝置位置。若您選擇在外部應用程式中開啟導航，該服務將依據其自身的隱私權政策處理請求。

開啟韓語學習網站、外部學校或資訊連結，或本政策頁面時，會使用您的瀏覽器及目的地服務，這些服務可依據其自身政策處理一般網頁請求資訊。

本政策託管於 GitHub Pages。GitHub 可依據其隱私權聲明處理請求資訊（包含 IP 位址）。託管本政策並不提供開發者任何應用程式學習資料後端。 GitHub Privacy Statement

6. 刪除與安全

若要刪除裝置上的所有應用程式紀錄，請開啟 Android 設定 → 應用程式 → Hanteum：校園韓語 → 儲存空間 → 清除儲存空間，或解除安裝應用程式。這也會刪除學習進度和設定。已複製的訊息、透過其他應用程式傳送的訊息，以及語音引擎下載的內容，須在各自的服務中另外管理。

開發者無法遠端取得或刪除僅儲存於您裝置上的記錄。本應用程式使用 Android 私密應用程式儲存空間；未宣稱額外端對端加密。

7. 支援與政策變更

若您透過電子郵件聯繫支援團隊，我們將收到您的電子郵件地址及您選擇發送之資訊。我們使用該資訊以回應並解決您的請求，並視需要保留往來記錄以符合相關義務。您可透過相同地址請求刪除，但須受上述義務限制。請標明 Hanteum：校園韓語，並避免發送密碼、學生證號或不必要之個人資訊。

當我們處理資訊之方式有所變更時，我們將更新本政策及其生效日期。
