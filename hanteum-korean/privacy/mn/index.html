Энэ бодлого нь Hanteum Korean: Campus Life аппын анхны туршилтын хувилбар болон дуу хоолойгоор дасгал хийдэг хувилбаруудад хамаарна. Аппад хэрэглэгчийн бүртгэлийн систем, зар сурталчилгааны SDK, хөгжүүлэгчийн дүн шинжилгээний SDK болон хөгжүүлэгчийн ажиллуулдаг сургалтын өгөгдлийн сервер байхгүй.

1. Таны төхөөрөмж дээрх суралцах мэдээлэл

Хадгалсан хэллэг, хичээлийн явц, дасгалын түүх, гарын авлагад хийсэн тэмдэглэгээ, тохиргоог төхөөрөмж дээрх аппын хувийн хадгалах хэсэгт хадгална. Хөгжүүлэгч таны сургалтын бүртгэлийг аппаар дамжуулан хүлээн авдаггүй.

Апп Android-ын автомат нөөцлөлтийг идэвхгүй болгож, өгөгдлөө үүлэн нөөцлөлт болон төхөөрөмж хоорондын шилжүүлэгт оруулдаггүй. Та Android-ын санах ой цэвэрлэх тохиргоог ашиглах эсвэл аппыг устгаж сургалтын бүртгэлээ арилгаж болно.

2. Зурвасын ноорог ба түр санах ой

Зурвасын загвар нь таны оруулсан мэдээллээр санах ойд түр урьдчилсан хувилбар үүсгэнэ. Маягтаас гарах эсвэл маягт дахин үүсэхэд ноорог арилна. Апп оруулсан мэдээллийг сургалтын бүртгэлд хадгалахгүй, хөгжүүлэгч рүү илгээхгүй.

Хуулах товчийг дарвал Android урьдчилсан хувилбарыг түр санах ойд хуулна. Хаана буулгах, илгээх эсэхээ та өөрөө шийднэ. Android, таны гарын апп болон текстийг хүлээн авах апп өөрсдийн тохиргоо, бодлогын дагуу текстийг боловсруулна. Шаардлагагүй оюутны дугаар эсвэл нууц мэдээлэл бүү оруулаарай.

3. Микрофоны нэмэлт зөвшөөрөл ба дуу хоолойн дасгал

Дуу хоолойн дасгалтай хувилбарт та бичихийг сонгоход апп микрофоны зөвшөөрөл хүснэ. Нэг удаад 30 секунд хүртэл бичиж, дахин сонсох боломжтой байлгахын тулд бичлэгийг аппын хувийн түр хадгалах хэсэгт хадгална. Апп бичлэгийг серверт илгээхгүй, бусадтай хуваалцахгүй, автоматаар дүгнэхэд ашиглахгүй.

Дуу хоолойн дасгалын хэсгээс бичлэгээ устгаж болно. Дасгалын хэллэгийг солих, дэлгэцээс гарах эсвэл өөр апп руу шилжихэд бичлэг арилна. Үлдсэн файл байвал аппыг дараагийн удаа нээхэд устгана. Микрофоны зөвшөөрөл өгөхгүй байсан ч хичээлийн текст болон жишээ аудиог ашиглаж болно.

4. Хичээлийн аудио ба Android-ын текст унших үйлчилгээ

Хичээлийн аудио багтсан хувилбаруудад жишээ бичлэгийг түгээхээс өмнө бэлтгэж, таны төхөөрөмж дээр тоглуулна. Бэлэн бичлэг байхгүй бол суулгасан офлайн солонгос хоолойгоор хичээлийн тогтсон текстийг уншуулж болно. Анхны туршилтын хувилбар Android-ын текст унших үйлчилгээг ашигладаг. Энэ үйлчилгээ өөрийн тохиргоо, нууцлалын бодлогын дагуу яриаг боловсруулж болно.

Хичээлийн үед апп таны бичлэг болон зурваст оруулсан мэдээллийг текст унших үйлчилгээ рүү дамжуулахгүй, үүлэн дуу үүсгэх API ашиглахгүй. Android-ын текст унших үйлчилгээ өөрийн хоолойн таталт, тохиргоог удирддаг. Дуу байхгүй байсан ч та хичээлийн текстийг уншиж болно.

5. Кампусын газрын зураг, вэбсайт ба бодлогын хостинг

Кампусын газрын зураг нь апптай хамт ирдэг газрын зургийн өгөгдлийг ашиглана. Апп таны төхөөрөмжийн байршлын мэдээлэлд ханддаггүй. Замын чиглэлийг өөр аппад нээвэл тухайн үйлчилгээ хүсэлтийг өөрийн нууцлалын бодлогын дагуу боловсруулна.

Хангыл суралцах сайт, гадаад сургууль эсвэл мэдээллийн холбоос, эсвэл энэ бодлогыг нээх үед таны браузер болон зорилтот үйлчилгээг ашигладаг бөгөөд тэдгээр нь өөрийн бодлогын дагуу ердийн вэб хүсэлтийн мэдээллийг боловсруулж болно.

Энэ бодлого GitHub Pages дээр байрладаг. GitHub нь өөрийн нууцлалын мэдэгдлийн дагуу IP хаяг зэрэг вэб хүсэлтийн мэдээллийг боловсруулж болно. Бодлогыг байршуулснаар хөгжүүлэгч сургалтын өгөгдөл хүлээн авах сервертэй болохгүй. GitHub Privacy Statement

6. Устгал болон аюулгүй байдал

Төхөөрөмж дээрх аппын бүх бүртгэлийг арилгахын тулд Android тохиргоо → Апп → Hanteum Korean: Campus Life → Хадгалах сан → Хадгалах санг цэвэрлэх хэсгийг сонгох эсвэл аппыг устгана. Ингэхэд хичээлийн явц, тохиргоо ч арилна. Хуулсан болон бусад аппаар илгээсэн зурвас, текст унших үйлчилгээний татсан хоолойг тухайн үйлчилгээн дээр тусад нь удирдана.

Зөвхөн таны төхөөрөмжид байгаа бүртгэлийг хөгжүүлэгч алсаас авах эсвэл устгах боломжгүй. Апп Android-ын хувийн хадгалах хэсгийг ашигладаг. Үүнээс гадна төгсгөл хоорондын шифрлэлт ашигладаг гэж мэдэгдээгүй.

7. Дэмжлэг болон бодлогын өөрчлөлт

Тусламжийн хаяг руу имэйл явуулбал таны имэйл хаяг болон явуулахаар сонгосон мэдээллийг хүлээн авна. Бид түүнийг хариу өгөх, хүсэлтийг шийдэхэд ашиглаж, энэ зорилго болон мөрдөх үүрэгт шаардлагатай хугацаанд захидал харилцааг хадгална. Мөрдөх үүргийн хүрээнд ижил хаягаар хандан устгахыг хүсэж болно. Hanteum Korean: Campus Life аппын нэрийг бичээд нууц үг, оюутны дугаар, шаардлагагүй хувийн мэдээлэл бүү илгээгээрэй.

Бид энэ бодлогыг болон үйлчлэх өдрийг мэдээллийг боловсруулах арга барил өөрчлөгдөхөд шинэчилнэ.
