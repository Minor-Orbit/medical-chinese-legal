Kebijakan ini berlaku untuk Hanteum Korean: Campus Life, termasuk pilot awal dan versi dengan latihan suara. Aplikasi ini tidak memiliki sistem akun, SDK periklanan, SDK analitik pengembang, atau server data pembelajaran yang dioperasikan pengembang.

1. Informasi pembelajaran di perangkat Anda

Tanda buku, kemajuan pelajaran, riwayat latihan, tanda centang panduan, dan pengaturan disimpan dalam penyimpanan aplikasi pribadi di perangkat Anda. Pengembang tidak menerima catatan pembelajaran Anda melalui aplikasi.

Aplikasi ini menonaktifkan cadangan Android otomatis dan mengecualikan datanya dari cadangan cloud Android dan transfer perangkat. Anda dapat menghapus catatan pembelajaran lokal menggunakan pengaturan Clear storage di Android atau dengan menghapus aplikasi.

2. Rancangan pesan dan papan klip

Template pesan menggunakan entri Anda untuk membuat pratinjau sementara di memori. Aplikasi menghapus draf ketika Anda meninggalkan atau membuat ulang formulir. Aplikasi tidak menyimpan entri ke catatan belajarnya atau mengirimkannya ke pengembang.

Ketika Anda memilih Salin, Android menempatkan pratinjau ke papan klipnya. Anda memilih di mana menempelkannya dan apakah akan mengirimkannya. Android, keyboard Anda, dan aplikasi tujuan menangani teks di bawah pengaturan dan kebijakan mereka sendiri. Hindari memasukkan ID siswa yang tidak perlu atau informasi pribadi yang sensitif.

3. Akses mikrofon opsional dan latihan suara

Pada versi dengan latihan suara, aplikasi meminta akses mikrofon ketika Anda memilih untuk merekam. Aplikasi merekam hingga 30 detik pada satu waktu dan menyimpan rekaman tersebut sementara di cache pribadinya agar Anda dapat mendengarkan kembali. Aplikasi tidak mengunggah atau membagikan rekaman tersebut atau menggunakannya untuk penilaian otomatis.

Anda dapat menghapus rekaman di Latihan suara. Aplikasi menghapusnya ketika Anda mengubah ekspresi latihan, meninggalkan layar latihan, atau beralih aplikasi. Aplikasi menghapus sisa file kapan pun aplikasi dibuka kembali. Teks pembelajaran dan audio contoh tetap tersedia jika Anda menolak akses mikrofon.

4. Audio pelajaran dan teks-ke-ucapan Android

Pada versi yang menyertakan audio pelajaran, rekaman contoh disiapkan sebelum aplikasi didistribusikan dan diputar pada perangkat Anda. Jika rekaman tertentu tidak tersedia, versi tersebut dapat membacakan teks pelajaran bahasa Korea yang telah disiapkan dengan suara Korea offline yang terpasang di Android. Versi uji coba awal memakai mesin text-to-speech Android untuk audio pelajaran. Mesin tersebut dapat memproses suara sesuai dengan pengaturan dan kebijakan privasinya sendiri.

Aplikasi ini tidak mengirimkan rekaman suara atau entri pesan ke mesin ucapan atau memanggil API generasi ucapan cloud selama pelajaran. Mesin ucapan Android Anda mengelola unduhan suara dan pengaturannya sendiri. Anda dapat melanjutkan membaca pelajaran jika suara tidak tersedia.

5. Peta kampus, situs web, dan hosting kebijakan

Peta kampus menggunakan data peta yang disertakan dalam aplikasi. Aplikasi tidak mengakses lokasi perangkat Anda. Jika Anda memilih untuk membuka petunjuk arah di aplikasi eksternal, layanan tersebut menangani permintaan tersebut di bawah kebijakan privasi mereka sendiri.

Membuka situs pembelajaran Hangul, tautan sekolah atau informasi eksternal, atau kebijakan ini menggunakan browser Anda dan layanan tujuan, yang dapat memproses informasi permintaan web normal di bawah kebijakan mereka sendiri.

Kebijakan ini dihosting di GitHub Pages. GitHub dapat memproses informasi permintaan, termasuk alamat IP, di bawah pernyataan privasi GitHub. Menghosting kebijakan ini tidak menyediakan backend data pembelajaran aplikasi bagi pengembang. GitHub Privacy Statement

6. Penghapusan dan keamanan

Untuk menghapus semua catatan aplikasi lokal, gunakan Pengaturan Android → Aplikasi → Hanteum Korean: Campus Life → Penyimpanan → Hapus penyimpanan, atau uninstall aplikasi. Ini juga menghapus kemajuan dan pengaturan. Pesan yang disalin, pesan yang Anda kirim melalui aplikasi lain, dan unduhan mesin suara harus dikelola secara terpisah di layanan tersebut.

Pengembang tidak dapat mengambil atau menghapus catatan secara jarak jauh yang hanya disimpan di perangkat Anda. Aplikasi ini menggunakan penyimpanan aplikasi pribadi Android; tidak ada klaim enkripsi end-to-end tambahan.

7. Dukungan dan perubahan kebijakan

Jika Anda mengirim email ke dukungan, kami menerima alamat email Anda dan informasi yang Anda pilih untuk dikirim. Kami menggunakannya untuk menanggapi dan menyelesaikan permintaan Anda serta menyimpan korespondensi sesuai kebutuhan untuk tujuan tersebut dan kewajiban yang berlaku. Anda dapat meminta penghapusan dengan menghubungi alamat yang sama, dengan tunduk pada kewajiban tersebut. Silakan identifikasi Hanteum Korean: Campus Life dan hindari mengirim kata sandi, ID siswa, atau informasi pribadi yang tidak perlu.

Kami memperbarui kebijakan ini dan tanggal berlakunya ketika penanganan informasi kami berubah.
