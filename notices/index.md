# 이용 및 콘텐츠 안내

이 앱은 병원 상황에서 사용하는 한국어와 중국어 표현을 연습하는 언어 학습 도구입니다.

- 의료기기가 아니며 진단, 치료, 처방 또는 전문적인 의료 조언을 제공하지 않습니다.
- 실제 진료 결정은 의료 전문가와 상의해야 합니다.
- 통역 연습은 특정 시험의 공식 문제나 공식 대비 과정이 아니며 합격을 보장하지 않습니다.
- 학습 문장은 실제 상황에서 문맥과 기관 지침에 맞게 확인해야 합니다.

앱의 자체 콘텐츠를 허가 없이 복제·재배포하지 마십시오. 제3자 상표와 서비스명은 각 권리자에게 귀속됩니다.
